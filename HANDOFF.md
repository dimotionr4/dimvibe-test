## Решения владельца
1. Один режим ответа на упражнение, выбирает преподаватель; смешивать режимы не нужно (2026-10-22; раньше смешивание было разрешено, решение отменено).
2. Пока каждый преподаватель работает сам у себя: без общих аккаунтов и общей библиотеки. Модель с аккаунтами (D-020) остаётся целевой на будущее.
3. Первый модуль: пропуски (Fill Blanks), до 10 пропусков на задание.
4. Выпадающий список собирается из всех пропусков задания (общий пул).
5. Картинка к инструкции: загрузить файл или указать ссылку.
6. Для Claude Code: папка проекта на компьютере, файлы из репозитория.
7. Черновик и публикация (вариант A, 2026-10-22): черновик хранится в браузере, «Опубликовать» скачивает файл упражнения, отправка через GitHub Desktop.
8. ID упражнения — случайный (`ex-k7m2qa`); `ex-001` остаётся.

## Редактор Fill Blanks: план первого шага (начат 2026-10-22)
1. Новый формат файла (format 2, описан в skill fill-blanks), плеер его читает, `ex-001.json` переведён. Сделано и проверено в LearnWorlds 2026-10-22.
2. `editor.html`, вкладка «Содержимое»: список черновиков, предложения, пропуски выделением, ответ/альтернативы/подсказка, ловушки, лимит 10, автосохранение в браузере.
   Сделано 2026-10-22: `editor.html` (ядро: черновики в localStorage, название, вкладки) + модуль `modules/fill-blanks/editor.js` и `editor.css`. Проверено в браузере Claude; владельцем на GitHub Pages — ещё нет.
3. Предпросмотр настоящим плеером, «Опубликовать» (проверка + скачивание файла + ссылка и код iframe), «Открыть файл», «Снять с публикации».
   Сделано 2026-10-22, проверено в браузере Claude; владельцем — ещё нет. Как устроено:
   - Предпросмотр: редактор открывает `index.html?preview=1` в рамке 600 px; плеер шлёт `dimvibe-preview-ready`, редактор отвечает `dimvibe-preview` с данными черновика (только тот же сайт).
   - Модуль отдаёт ядру `exportData` (чистый файл: без пустых предложений и стёртых пропусков), `validate` (ошибки блокируют публикацию, предупреждения нет) и `load` (файл → черновик).
   - Статус публикации хранится в черновике (`publication`): что и когда скачано; редактор не знает, отправлен ли файл на GitHub.
   - Кэш: GitHub Pages разрешает браузеру хранить файл 10 минут, и обновлённая вкладка могла получить новую страницу со старым модулем (так у владельца завис предпросмотр на «Загрузка…»). Поэтому файлы модуля и плеер в предпросмотре подключены с номером версии `?v=3` (в `editor.html` три места: `<link>`, `<script>`, константа `ASSET_V`). При изменении `modules/fill-blanks/editor.js` или `editor.css` увеличивайте номер во всех трёх местах. Если плеер не ответил за 5 секунд, редактор показывает понятное сообщение.
