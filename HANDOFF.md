# Передача проекта DimVibe: текущее состояние (2026-10-26)

Короткая сводка для нового чата: что есть, что не проверено, что дальше. Сначала прочитайте `CLAUDE.md`, затем этот файл. Правила модуля — в его skill (`.claude/skills/<модуль>/`), они загружаются сами при работе с модулем.

**Как вести этот файл:** здесь только текущее состояние, не журнал. Подробная запись о каждом шаге (что сделано, как устроено, номера версий, уроки) идёт в конец `docs/HISTORY.md`; здесь — в лучшем случае одна строка в таблице модулей или в «Не проверено». Держать файл в пределах 2–3 экранов.

## Работа с владельцем
- Владелец не программист, работает в Claude Desktop (вкладка Code). Язык общения — русский, простыми словами, маленькими шагами, решения — за владельцем (подробно — `CLAUDE.md`, раздел 1).
- Публикация: Claude меняет файлы, владелец отправляет их через GitHub Desktop (Commit to main → Push origin). Git в командной строке не установлен.
- GitHub Pages обновляет сайт за 1–2 минуты, браузер может ещё до 10 минут держать старую копию (помогает Ctrl+F5).

- Кэш: файлы модулей и `core/` подключены с номером `?v=`. После правки файла поднять его номер во всех местах подключения; общий номер модулей в редакторе — `ASSET_V` (сейчас 73).
- Левая панель: на табло, в «Моих упражнениях» и «Настройках» — общая `core/sidebar.js`; редактор рисует свою. Пункты меняются в обоих местах.

## Уроки (чтобы не наступать снова)
- Не называть глобальные функции `open`, `close`, `print`, `name`, `event` — они затеняют функции окна браузера.
- Скрытие проверять по реальному `display` и высоте: правило `display:…` перебивает атрибут `hidden`.
- Comic (`core/rough.js`): при смене стиля убирать нарисованные контуры; не перезаписывать `textContent` у элементов с контуром без повторного `roughen()`.
- При правке файлов из PowerShell не добавлять BOM в начало `.html`; спецсимволы `` `r ``, `` `a ``, `` `f `` в строках PowerShell портят текст.

## Как не тратить много токенов (решение владельца 2026-10-26)
- Одна задача — одна сессия: закончили модуль или правку, закоммитили — открываем новый чат. Длинные чаты самые дорогие: каждый ответ заново перечитывает всю переписку.
- Перед закрытием сессии обновить этот файл (текущее состояние) и добавить запись в конец `docs/HISTORY.md`. Журнал шагов сюда не писать.
- Браузер Claude запускать один раз после группы правок, а не после каждой; по просьбе владельца — не запускать, проверяет владелец.
- Файлы читать кусками (поиск, затем нужные строки), а не целиком; `docs/HISTORY.md` и `docs/spec/` не открывать без нужды.
- Для мелких правок (текст, цвет, небольшой баг) можно выбрать более лёгкую модель в приложении.
- Расход за 22–26.10: около 123 млн условных токенов; больше всего — правка файлов и браузер.
