# Передача проекта DimVibe: состояние на 2026-10-22

Этот файл нужен, чтобы продолжить работу в новом чате или новом аккаунте Claude. Новый чат не знает ничего из предыдущих разговоров, поэтому всё нужное записано здесь и в `CLAUDE.md`. Сначала прочитайте `CLAUDE.md`, затем этот файл.

## Кто владелец и как с ним работать
- Владелец не программист. Работает с Claude Desktop (вкладка Code), код пишет Claude.
- Говорить простым языком, маленькими шагами. Перед шагом: что делаем, какой результат, как проверить.
- Решений за владельца не принимать: давать 2–3 варианта с плюсами и минусами и рекомендацию.
- Язык общения: русский. Интерфейс проекта: EN и RU, позже грузинский.

## Что уже сделано
- Прототип DimVibe (Google AI Studio) изучен как референс. Новый проект строим с нуля.
- Выбран хостинг: GitHub Pages для страницы плеера и файлов упражнений (аккаунт `dimotionr4`), Cloudflare R2 для картинок и аудио (пока не подключён, условия бесплатного тарифа проверить на официальном сайте). Запасные: Firebase Hosting и Cloudflare Pages. Firebase Storage не использовать (требует тариф Blaze).

- Упражнение Fill Blanks на тестовой странице: три режима ответа (банк слов, выпадающий список, ввод вручную) переключаются кнопками; сейчас в `ex-001.json` одно английское предложение с двумя пропусками (по решению владельца мультиязычность в тесте не нужна).

- Плеер (`index.html`): шапка и низ с кнопкой «Проверить» закреплены, прокручивается только текст; порядок слов в банке и списках перемешивается один раз на прохождение; при `"published": false` в файле упражнения или если файла нет, показывается «Упражнение сейчас недоступно» без кнопок.
- Публикация: Claude меняет файлы, владелец отправляет их через GitHub Desktop (Commit to main, Push origin). Git в командной строке не установлен.

## Решения владельца
1. Внутри одного задания разрешено смешивать режимы ответа. Это отличается от архива (D-028), пока архив не обновлён.
2. Пока каждый преподаватель работает сам у себя: без общих аккаунтов и общей библиотеки. Модель с аккаунтами (D-020) остаётся целевой на будущее.
3. Первый модуль: пропуски (Fill Blanks), до 10 пропусков на задание.
4. Выпадающий список собирается из всех пропусков задания (общий пул).
5. Картинка к инструкции: загрузить файл или указать ссылку.
6. Для Claude Code: папка проекта на компьютере, файлы из репозитория.

## Открытые вопросы
- Мобильный режим плеера (прокрутка, доступность кнопки «Проверить», клавиатура): владелец отложил, сначала десктоп.
- Медиа: подключить Cloudflare R2, проверить условия бесплатного тарифа.
- Темы: в архиве Classic и Comic; владелец хочет светлую и тёмную. Оба варианта или один?
- Состав первого релиза и порядок остальных модулей.
- Инструмент разработки: Claude Desktop (вкладка Code) выбран; правила из архива (AI_DEVELOPER_RULES) не адаптированы.

## Спецификация
Полный архив `DimVibe_Specification_Kit_v32` (81 файл) лежит в `docs/spec/` — источник утверждённых решений. Не читать целиком: открывать только файлы нужного модуля.
Правила модулей вынесены из `CLAUDE.md`: Fill Blanks — skill `.claude/skills/fill-blanks/`, остальные — `docs/MODULE_NOTES.md` (переносятся в skills по одному, по мере работы).
Порядок приоритета: последнее явное решение владельца, затем `DECISIONS.md`, затем документ области (см. `GOVERNANCE.md` в архиве).

## Что делать в новом чате
1. Клонировать репозиторий `dimvibe-test` на компьютер (GitHub Desktop).
2. Положить в корень `CLAUDE.md`, этот файл `HANDOFF.md` и папку `docs/spec/` с архивом.
3. В Claude Desktop открыть вкладку Code на этой папке.
4. Первое сообщение: «Прочитай CLAUDE.md и HANDOFF.md. Предложи план первого шага, ничего не меняя».
