# Multiple Choice (выбор из вариантов) — четвёртый модуль

Спецификация: `docs/spec/04_MODULES/MULTIPLE_CHOICE.md` (D-040…D-045, MC-AC-01…18). Решения владельца 2026-10-23: этап 1 — текст, этап 2 (2026-10-24) — картинки, увеличение, озвучка; размер и вписывание картинок общие (вкладка «Дизайн»), положение картинки вопроса у каждого вопроса, увеличение только значком (наведением нет), источники картинок — загрузка, медиатека, ссылка https; в показе «по одному» одна попытка на вопрос (как в True / False; в спецификации иначе, решение владельца важнее); лимиты 10 вопросов и 8 вариантов (в спецификации лимита нет); пояснений к вопросам нет; метки по умолчанию буквы A, B, C; показ верных в конце — выключатель, по умолчанию выкл.

## Что общего с остальными модулями
Ядро (вкладки, инструкция, цвет, Classic/Comic, макет, «Проверить», число проверок «авто» 1–5, закрепление, «Начать заново», публикация). Каждый вопрос — «пропуск» общего хода: `unitPlayer()` в `index.html` (общий механизм с True / False: `units`, `reset`, `goMissing`, `missingNote`, `instant`, `render`). `answer` — верный набор (ID вариантов по алфавиту через запятую), `value` — выбранный в том же виде; сравнение — общий `check()`. Вопрос не расходует проверку, пока нет ни одного выбранного варианта. 1 балл за вопрос только за точный набор.

## Формат файла (format 1)
```json
{ "id":"ex-…", "module":"multiple_choice", "format":1, "view":"one", "mode":"single", "labels":"letters", "shuffle":true, "showCount":true, "showCorrect":true,
  "items":[{"id":"q1","text":"…","mode":"multiple","options":[{"id":"o1","text":"…"}],"correct":["o1","o3"]}] }
```
- `mode` на верхнем уровне — тип по умолчанию, у вопроса в файле всегда готовый `mode` (`single`/`multiple`). `view`: `one` (по умолчанию) / `list`. `labels`: `letters` / `numbers`. `shuffle` (нет поля — включено), `showCount`, `showCorrect` (нет — выключено).
- Черновик: у вопроса `mode: ''` — «как в общих», иначе `single`/`multiple`; `correct` — массив ID. Переключение Single ↔ Multiple не стирает отметки; в Single с несколькими верными публикация блокируется.

## Редактор (`modules/multiple-choice/editor.js`, `editor.css`)
Блок «Тип вопросов» (общий Single/Multiple), карточки вопросов (раскрывается одна: текст, тип «Как в общих / Single / Multiple», варианты — слева отметка верного: круг для Single (выбор заменяет прежний, повтор снимает), квадрат для Multiple; справа поле текста; «×» убрать, «+ Вариант» до 8), добавить/дублировать (новые ID)/удалить (подтверждение в строке)/вверх-вниз/перетаскивание. По умолчанию 4 пустых варианта. Метки вариантов (буквы / цифры) переключаются над вариантами в «Содержимом» и бледно видны внутри отметок (поле `labels`, одно на упражнение; в «Дизайне» их нет). `designOptions`: только показ вопросов; `behaviorOptions`: перемешивание, «Выберите N правильных ответов», «Показать верные ответы в конце» (ядро рисует их во вкладках «Дизайн» и «Поведение»). Хук `unitCount` для «авто» проверок.

## Публикация
Ошибки: нет вопросов или больше 10; нет текста вопроса; меньше двух вариантов; пустой вариант; нет верного; в Single больше одного верного. Замечания: одинаковые варианты; Multiple с одним верным.

## Плеер (`modules/multiple-choice/player.js`, `player.css`)
- Варианты — кнопки: круг (Single) или квадрат (Multiple), метка A/B/C или 1/2/3 по текущему порядку, текст. Порядок перемешивается один раз при открытии (в `units()`), «Начать заново» его не меняет.
- «По одному» (одна попытка): Single засчитывается сразу по нажатию; Multiple — кнопкой «Ответить» (активна при ≥1 выбранном). Дальше вопрос закреплён (верно или неверно), «Проверить» скрыта, внизу «Отвечено n из N · Верно k»; после последнего упражнение завершено. Ряд номеров с отметками и «Предыдущий / Следующий» (классы `tf-*` из True / False).
- «Списком»: все вопросы, общая «Проверить» с числом проверок: верные закрепляются, неверные меняются; неполный ответ проверку не тратит.
- Для ошибочного Multiple Select отдельные варианты не раскрываются: итог только на карточке («✗ Неверно»). У Single выбранный вариант красный/зелёный.
- «Показать верные ответы» (если включено, после завершения, есть неверные): кнопка отмечает верные варианты («✓ верный»).
- Картинки и звук (этап 2): в файле `items[i].image {media|url, alt, align: top|bottom|left|right}`, `items[i].audio {media}`, `options[k].image {media|url, alt}`, `options[k].audio {media}`, верхний уровень `imageSize` s|m|l (по умолчанию m) и `imageFit` contain|cover. Вариант может быть только текстом, только картинкой или обоими; без текста и картинки — пустой (ошибка публикации). Если хоть у одного варианта вопроса есть картинка, варианты идут сеткой, иначе списком. Значок увеличения `⤢` открывает общий просмотр `core/mediaviewer.js` (`openMediaViewer(src, alt)`, `?v=1`, закрывается ×, Esc, щелчком мимо), значок звука — общий `audioButton`; оба — отдельные кнопки поверх варианта (`.mc-ow-tools`), ответ не выбирают. Картинка вопроса: сверху/слева — перед текстом, снизу/справа — после; сбоку не шире 45%. В редакторе: блок «Картинка и звук вопроса» (загрузка, медиатека, ссылка, описание, положение) и значок картинки у каждого варианта, раскрывающий панель картинки и звука. Ошибки: ссылка не https; замечания: нет описания у картинки вопроса, вариант-картинка без текста и описания.
- Не сделано: наведение мышью для увеличения (решение владельца 2026-10-24 — не делать), настоящая загрузка файлов и звук в бою (нужен вход владельца).
