# Word Scramble / Sentence Builder (одиннадцатый модуль)

Спецификация: `docs/spec/04_MODULES/WORD_SCRAMBLE_BUILDERS.md` (WS-01…WS-04, модуль 13 архива), решения D-093…D-096 в `docs/spec/DECISIONS.md`, приёмка WS-AC-01…28 (не путать с Word Search: `word-search:WS-AC-…`) в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-25 («все рекомендации»: 1А, 2А, 3В, 4А, 5Б, 6А, 7Б):
1. Три вида задания — «Слово» (кусочки — буквы), «Фраза», «Предложение» (кусочки — слова); вид выбирается у каждого задания, в одном упражнении можно смешивать.
2. Кусочки задаются **прямо в ответе**: без разметки режется автоматически (слово — на графемы через `Intl.Segmenter`, буква с ударением или составной знак — один кусочек; фраза и предложение — по пробелам, знаки препинания остаются у слова: `Hello,`, `London.`); своя нарезка — косой чертой: `I have / been to / London.`, `app / le`. Ответ — единственный источник кусочков, отдельного списка кусочков нет, поэтому ручная нарезка не теряется при правке (кнопки «склеить / разрезать» и «нарезать заново» из архива не делали).
3. Показ заданий — настройка «Дизайна» «Показ заданий»: по одному (по умолчанию, номера и «Предыдущее / Следующее») или все сразу.
4. Проверка одна, итоговая, на все задания (D-095), как у Ordering и Timeline.
5. Правильный ответ у неверного задания — выключатель «Поведения» «Показывать правильный ответ», по умолчанию включён. Пояснение показывается после проверки всегда.
6. Ученик двигает кусочки **только нажатием**: из банка — в конец ответа, из ответа — обратно в банк. Перетаскивания нет (можно добавить позже, если будет не хватать).
7. Этап 1 (сделан 2026-10-25) — ответ, вид, своя инструкция, подсказка, пояснение, «Вид кусочков» (плитки / чипсы). **Этап 2** (не сделан) — картинка и звук у задания через общие `MediaUI.imageControl` / `MediaUI.picker`, в плеере `addZoom`.
- Лимиты: до 10 заданий, в задании от 2 до 20 кусочков, ответ до 300 символов.

## Что делает ученик
Видит поле ответа (пунктирная рамка, «Нажимайте на кусочки ниже…») и банк перемешанных кусочков. Нажатие на кусочек в банке ставит его в конец ответа, нажатие на кусочек в ответе возвращает его в банк. Подсказка открывается кнопкой «💡 Подсказка», бесплатно. Строка внизу: «Заполнено: N из M» (готовые задания — в которых использованы все кусочки). «Проверить», пока не все задания собраны, проверку не тратит: «Соберите все задания: не готово ещё N», несобранное задание с красной рамкой, при показе по одному открывается первое такое. После проверки кусочки не нажимаются; рамка ответа зелёная с ✓ или красная с ✗, у неверного — «Правильно: …» (если включено), ниже пояснение. Номера заданий окрашиваются.

## Проверка и баллы
- Единица общего хода — задание: `answer` — правильный текст, `value` — собранный текст, только когда использованы все кусочки (иначе пусто). Плеер даёт `maxChecks() = 1`, свой `check()` (`{note}` при несобранных, иначе `{done}`), `started()`.
- 1 балл за полностью верное задание. Сравниваются **значения** кусочков по порядку (Unicode NFC, регистр и знаки важны), а не их номера: одинаковые кусочки взаимозаменяемы (две P в `apple`).
- Банк перемешивается при каждом прохождении так, чтобы значения не стояли в правильном порядке; в предпросмотре держится, пока кусочки те же.

## Редактор
Карточка задания (при нескольких — «Задание N», выше / ниже / копия / удаление с подтверждением): три кнопки вида, поле ответа (жирное), строка «Свои кусочки — через косую черту…», под ней сразу видны кусочки и красное замечание, если ответ не годится; поля с подписями слева: «Инструкция», «Подсказка», «Пояснение». Новое задание — того же вида, что последнее. «Дизайн»: «Показ заданий» (`view`), «Вид кусочков» (`tokenStyle`: tiles / chips); макет — флаг `tf`. «Поведение»: «Проверок на прохождение: 1» (`fixedChecks`, `fixedChecksNote`) и «Показывать правильный ответ». `demo()`: три задания всех видов (`apple` с подсказкой и пояснением, `a cup of tea` со своей инструкцией, `I have / been to / London.`).

## Публикация (validate)
Ошибки у задания: нет ответа; в «Слове» пробелы (без косых черт) — «выберите „Фраза“»; меньше 2 кусочков; больше 20; все кусочки одинаковые (нельзя перемешать, например `aa`). Повторяющиеся кусочки — не ошибка. Предупреждений нет.

## Файл упражнения
```json
{ "module": "word_scramble", "format": 1, "view": "list", "tokenStyle": "chips", "showAnswers": false,
  "tasks": [{ "id": "t1", "mode": "word", "answer": "apple", "hint": "A red or green fruit.", "explanation": "…" },
            { "id": "t2", "mode": "sentence", "answer": "I have / been to / London.", "instruction": "…" }] }
```
Кусочки в файл не пишутся: плеер режет `answer` тем же правилом (`modules/word-scramble/tokens.js`). `view` пишется только при «list», `tokenStyle` — только при «chips», `showAnswers` — только при выключенном; `instruction`, `hint`, `explanation` — только если не пустые. Неизвестный `mode` читается как `sentence`.

## Файлы
`modules/word-scramble/`: `tokens.js` (`WordScrambleTokens`: `MODES`, `split`, `join`, `text`, `same` — подключается и в `editor.html`, и в `index.html` перед своим модулем), `editor.js` (`WordScrambleEditor`), `editor.css`, `player.js` (`WordScramblePlayer`), `player.css`. Классы с приставкой `ws-`; номера и «Предыдущее / Следующее» — `tf-dots`, `tf-pager` (CSS True / False). Кусочки — кнопки `.ws-tok` (Comic рисует им контур).

## Не проверено
Настоящий палец на телефоне, Safari/Firefox (в старых браузерах без `Intl.Segmenter` буквы режутся по символам — составные знаки могут распасться), LearnWorlds iframe; владельцем — ещё нет.
