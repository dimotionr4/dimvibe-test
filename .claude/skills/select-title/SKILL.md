# Select Title (восьмой модуль)

Спецификация: `docs/spec/04_MODULES/SELECT_TITLE.md` (ST-01…ST-04, модуль 06 архива).

Решения владельца 2026-10-25 («все рекомендации»):
- Отдельный модуль со своим редактором и плеером (не режим Multiple Choice); приёмы взяты из Multiple Choice, сам он не менялся.
- Проверка как в архиве: и при показе «по одному», и «все сразу» — одна общая «Проверить» для всех текстов (стандартный ход `index.html`), число проверок по общему правилу (3 при 1–5 текстах, в «Поведении» 1–5). Не как «по одному» в Multiple Choice (там ответ сразу, одна попытка).
- Этап 1 — текст: абзацы, заголовки, пояснение, перемешивание, показ по одному / все сразу.
- Этап 2 (решение владельца 2026-10-25: «нужны») — у каждого текста необязательные картинка и звук (озвучка текста), как в Mistake Mode: в редакторе общие значки `MediaUI.imageControl` и `MediaUI.picker('audio')` над полем текста; в плеере картинка над текстом с кнопкой увеличения ⤢ и под ней «Слушать». Просмотр и прослушивание не тратят проверок и не меняют выбор. Во вкладке «Дизайн» «Размер картинок» (S/M/L, высота 110 / 180 / 260 px) и «Картинка в рамке» (вписать / заполнить) — только если в упражнении есть картинка. Положения картинки слева / справа от текста нет (только сверху).
- Лимиты: до 5 текстов, от 2 до 6 заголовков у текста (новый текст — 4 пустых поля), текст до 400 слов.
- Оформление текста — обычный текст: пустая строка начинает абзац, одиночный перенос сохраняется. Жирного и курсива нет.

## Что делает ученик
Читает текст целиком (без обрезки и своей прокрутки), под ним строка «Выберите заголовок, который подходит лучше всего.» и крупные кнопки заголовков без букв. Нажатие выбирает заголовок, другое нажатие заменяет выбор. Несколько текстов: «по одному» (номера сверху, «Предыдущий / Следующий») или «все сразу» с подписями «Текст N».

## Проверка и баллы
- Единица общего хода — текст: `answer` = ID правильного заголовка, `value` = ID выбранного; 1 балл за текст.
- «Проверить» требует выбор у всех текстов; иначе проверка не тратится, карточка без выбора — с красной пунктирной рамкой, при «по одному» показывается первый такой текст.
- Верный выбор закрепляется (зелёный, ✓); неверный — красный с ✗, его можно поменять (новый выбор снимает пометку).
- Пояснение — после верного ответа или в конце. В конце у неверно отвеченного текста правильный заголовок — зелёная пунктирная рамка и ✓; правильный до конца не раскрывается.
- Перемешивание (по умолчанию включено, выключатель в «Поведении», `shuffle: false` в файле): порядок выбирается один раз при открытии и хранится по набору ID заголовков, поэтому при правках в предпросмотре не «прыгает»; «Начать заново» его не меняет (как в Multiple Choice).

## Редактор
Текст (поле, счётчик слов), блок «Заголовки»: кружок слева — отметить правильный (ровно один, хранится ID), поле, выше / ниже / удалить (не меньше 2 полей). Удаление правильного снимает отметку. «+ Заголовок» до 6. Пояснение (необязательно). Несколько текстов: вверх / вниз, копия (новые ID текста и заголовков, отметка правильного переходит на копию того же заголовка), удаление с подтверждением, если текст не пустой. «Дизайн»: «Показ текстов» (`view`); макет — общие кнопки ответа (флаг `tf`).

## Публикация (validate)
Ошибки: нет текстов; больше 5; пустой текст; больше 400 слов; меньше 2 заполненных заголовков; больше 6; не отмечен правильный или он пустой; одинаковые заголовки в одном тексте (без учёта регистра и лишних пробелов; в разных текстах можно). Пустые поля заголовков не ошибка — в файл не попадают.

## Файл упражнения
```json
{ "module": "select_title", "format": 1, "view": "list", "shuffle": false,
  "imageSize": "m", "imageFit": "contain",
  "texts": [{ "id": "t1", "image": { "media": "media/…/img.jpg", "alt": "" }, "audio": { "media": "media/…/aud.mp3" },
              "text": "Абзац 1\n\nАбзац 2",
              "options": [{ "id": "o1", "text": "Birds of the Lake" }, { "id": "o2", "text": "A Cold Winter" }],
              "correct": "o1", "explanation": "…" }] }
```
`view` пишется только при «list», `shuffle` — только при выключенном, `explanation` — только если не пустое; `image` (`media` или `url`), `audio` — только если есть, `imageSize` / `imageFit` — только если в упражнении есть картинка. Неправильная ссылка на картинку (не https) — ошибка публикации. ID заголовков уникальны во всём упражнении. При загрузке повтор ID получает новый, `correct` на несуществующий заголовок — пустой (ошибка публикации).

## Файлы
`modules/select-title/`: `editor.js` (`SelectTitleEditor`), `editor.css`, `player.js` (`SelectTitlePlayer`), `player.css`. Классы с приставкой `st-`; номера и «Предыдущий / Следующий» — `tf-dots`, `tf-pager` (CSS True / False). В `index.html` класс `.st-card.missing` добавлен в поиск первой незаполненной карточки.

## Не проверено
Настоящий палец на телефоне, Safari/Firefox, LearnWorlds iframe, настоящая загрузка файла картинки и звука (нужен вход владельца; показ проверен на файлах из ex-ugfvkv).
