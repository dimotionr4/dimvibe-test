# Hotspot (семнадцатый модуль)

Спецификация: `docs/spec/04_MODULES/HOTSPOT.md` (HS-01…HS-04, модуль 18 архива), решения D-117 и далее в `docs/spec/DECISIONS.md`, приёмка HS-AC-01…36 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-26 (этап 1, вариант A «Зона + Точка, “Найти один” и “Найти несколько”»):
1. Один способ ответа на всё упражнение (общее правило проекта, раздел 2 `CLAUDE.md`; в архиве способ у каждого задания свой): «Зона» (нажать на готовую область) или «Точка» (поставить маркер). Выбирает преподаватель в редакторе, ученик не переключает.
2. Схема задания не выбирается отдельно: одна верная область — «найти одно», несколько — «найти несколько» (по числу отмеченных верных областей, до 10). «Найти по порядку» и ответ «Контур» (рисование, IoU) — следующие этапы.
3. Формы областей: прямоугольник и эллипс (многоугольник — позже). Область хранится описывающим прямоугольником в долях картинки 0–1.
4. Ученики работают касанием и мышью: клавиатуру и масштабирование щипком не добавляем (решение от 2026-10-24); описания картинки для незрячих нет.

## Что делает ученик
- В карточке задания — текст задания (или «Нажмите на нужную область картинки.» / «Поставьте маркер на нужное место.», при нескольких верных — с числом) и картинка. Заданий несколько — сверху номера, внизу «Предыдущее / Следующее» (`tf-dots`, `tf-pager`).
- «Зона»: все области видны тонкой линией, нажатие выбирает область, повторное — снимает. В «найти одно» новая область заменяет прежнюю; в «найти несколько» отметок не больше, чем верных областей (лишнюю надо сначала снять, иначе сообщение).
- «Точка»: области скрыты; нажатие на картинку ставит маркер (в «найти одно» маркер переставляется), нажатие на маркер убирает его. Маркеров не больше, чем верных областей. Попадание на границу засчитывается с допуском 0,6% ширины картинки (`HotspotGeo.TOL`).
- Строка внизу: до первой проверки «Отмечено: n из N», потом «Верно · Неверно · Проверок осталось», в конце «Результат: x из N (p%)».

## Проверка и баллы
- Единица общего хода — одна верная область одного задания (`id` = `задание:область`); 1 балл за единицу. Число проверок общее: 3 при 1–5 единицах, 5 при 6+, автор выбирает 1–5.
- Своя проверка (`check()`): пока в каком-то задании отметок меньше, чем осталось найти, проверка не тратится, показывается «Выберите области: ещё n» / «Поставьте маркеры: ещё n», карточка получает красную пунктирную рамку, показывается первое такое задание. Без загрузившейся картинки проверки нет.
- Верные отметки закрепляются (зелёные, ✓), неверные остаются красными с ✗ и их можно снять и поставить заново. «Точка»: каждой отметке — своя область, наибольшее паросочетание (`HotspotGeo.assign`), а не подсчёт.
- «Найти несколько»: в конце каждая оставшаяся неверная отметка отнимает 1 балл от найденных в этом задании, не ниже нуля (решение архива HS-04 C; «найти одно» вычета нет). Процент в итоге считается с вычетом (`percent()`).
- В конце ненайденные верные области показываются зелёным пунктиром с ✓ и подписью-названием; пояснение задания — после того как все его области найдены или в конце.

## Редактор
Четыре блока: 1) картинка (общий `MediaUI.imageControl`); 2) «Как отвечает ученик» — «Зона» / «Точка»; 3) «Области на картинке» — холст с инструментами «Выбрать и двигать», «Прямоугольник», «Эллипс» (рисование и перемещение указателем, 8 ручек размера у выбранной области; номера на областях) и список областей с названием «для себя» и крестиком; 4) «Задания» — текст, кнопки верных областей, пояснение, выше / ниже / копия / удаление. Удаление области убирает её из заданий и пишет сообщение. «Дизайн» и «Поведение» пока без настроек модуля (общий макет с кнопками ответа — флаг `tf`).
Не сделано (этап 4 и позже): подсветка до проверки, показ границ в «Точке», прозрачность, числовые координаты, многоугольник, масштаб/панорама, замена картинки с повторной проверкой геометрии.

## Публикация (validate)
Ошибки: нет картинки (или ссылка не https); нет областей; область с неверными размерами или за краем картинки; нет заданий; у задания нет верной области или все удалены; больше 30 областей, 20 заданий, 10 верных в задании; в режиме «Зона» две области пересекаются (ученик не сможет выбрать нужную). Предупреждения: очень маленькая область (сторона меньше 2%), одинаковые названия, в режиме «Точка» пересекаются верные области одного задания.

## Файл упражнения
```json
{ "module": "hotspot", "format": 1, "interaction": "point",
  "image": { "media": "media/…/img.jpg" },
  "zones": [{ "id": "z1", "label": "Спальня", "shape": "rect", "x": 0.22, "y": 0.2, "w": 0.16, "h": 0.17 },
            { "id": "z2", "shape": "ellipse", "x": 0.72, "y": 0.12, "w": 0.2, "h": 0.25 }],
  "tasks": [{ "id": "t1", "prompt": "Где спальня?", "targets": ["z1"], "explanation": "Bedroom — спальня." }] }
```
`interaction` пишется только при «point»; `label`, `prompt`, `explanation` — только если не пустые; числа округлены до 4 знаков. Области без верных ответов остаются (в «Зоне» это неверные варианты). При загрузке повтор ID получает новый, `targets` на несуществующую область отбрасываются, форма по умолчанию — прямоугольник; файл без заданий не открывается.

## Файлы
`modules/hotspot/`: `geometry.js` (`HotspotGeo`: valid, hit, overlap, assign — общий для редактора и плеера, подключён в `editor.html` и `index.html`), `editor.js` (`HotspotEditor`: create, demo, render, load, exportData, validate, unitCount), `editor.css`, `player.js` (`HotspotPlayer`), `player.css`. Классы `hs-`. Версии: geometry ?v=1, editor.js ?v=3, editor.css ?v=2, player.js ?v=2, player.css ?v=2, ASSET_V 83. Поверх картинки — SVG с `viewBox="0 0 1 1"` и `preserveAspectRatio="none"`, поэтому области не зависят от размера картинки; значки ✓ ✗ и маркеры — HTML-элементы в процентах.

## Не проверено
Настоящий палец на телефоне (рисование областей в редакторе рассчитано на мышь), Safari/Firefox, LearnWorlds iframe, настоящая загрузка своей картинки (демо берёт план дома из медиатеки), Comic на глаз, тёмная тема; владельцем — ещё нет. Проверено в браузере Claude синтетическими событиями: рисование, перемещение и изменение размера области, удаление, демо проходит validate, файл туда-обратно, плеер «Зона» (неполный ответ не тратит проверку, неверная отметка и исправление, вычет в конце: 2 из 5 вместо 3), «Точка» (замена маркера, предел маркеров, засчитывание), узкая ширина без прокрутки вбок, консоль без ошибок.
