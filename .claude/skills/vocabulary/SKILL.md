# Vocabulary (девятнадцатый модуль)

Спецификация: `docs/spec/04_MODULES/VOCABULARY.md` (VC-01…VC-04, модуль 21 архива), приёмка VC-AC-01…32 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-26 (этап 1, «все рекомендации»):
1. Это **справочник, не задание**: нет баллов, проверок, попыток, таймера, итога и учёта прохождения. Поиск, фильтр и открытое слово живут только в открытой странице.
2. Этап 1: слова с несколькими значениями и примерами, картинка слова; виды «Словарь» (поиск, фильтр по части речи, сортировка «А–Я») и «Карточки». Режимы «Показать» (Reveal) и «Слушать», озвучка слов и примеров, картинка у значения, CSV/TSV-импорт, запись голоса, озвучка браузером (TTS), скорости воспроизведения, RTL, языковые метки — **позже**.
3. Ввод — подробный редактор (карточка слова с вложенными значениями и примерами). «Вставка списком» — возможное улучшение.
4. Показ: на широком экране (от 720 px) список и подробности рядом, на узком — одно из двух, кнопка «‹ К списку».

## Формат файла
`{module: 'vocabulary', format: 1, view?: 'cards', imageSize?, imageFit?, words: [{id, text, ipa?, image?: {media|url, alt}, meanings: [{id, pos, translation, note?, examples?: [{id, text, translation?}]}]}]}`
- ID слова, значения и примера (`w1`, `m1`, `e1`) устойчивы: не зависят от текста и места.
- `pos`: noun, verb, adj, adv, pron, prep, conj, interj, phrase, other (названия — в `POS` редактора и плеера).
- Лимиты: слов до 60, значений у слова до 5, примеров у значения до 4.
- Пустые значения и примеры в файл не попадают; `view` пишется только `cards` (иначе словарь), размер и вписывание картинок — только если картинки есть.

## Проверка и публикация
- Ошибки: нет слов; не написано слово; нет значения с переводом; не выбрана часть речи; пример-перевод без примера; ссылка на картинку не `https://`.
- Предупреждения: повтор написания слова (не склеивать автоматически), нет примеров у слова.
- `unitCount` = число слов, `noChecks` = true (вкладка «Поведение» объясняет, что проверок нет, как у Essay Writing).

## Как работает в общем плеере
- `units()` пуст, `instant()` true, `status()` пуст. Новый крючок ядра: `noFooter()` у плеера → `index.html` ставит `body.no-footer`, нижняя панель («Проверить» и строка результата) скрыта (`modules/vocabulary/player.css`). У других модулей крючка нет, их нижняя панель не менялась.
- Кнопка «Начать заново» (↻) сбрасывает вид, поиск и фильтр.
- Поиск обновляет только список, поле ввода не пересоздаётся. Ищет по слову и по переводам всех значений (NFC, без учёта регистра).
- Карточки следуют порядку автора (или «А–Я», если включена сортировка в словаре); поиск и фильтр на них не действуют.
- Демо: `VocabularyEditor.demo` (три слова, у `house` два значения и картинка).
