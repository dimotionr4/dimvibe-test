# Медиатека (общая библиотека картинок)

Спецификация: `docs/spec/08_AUTHOR_STUDIO/MEDIA_LIBRARY_AND_STORAGE.md`, `docs/spec/04_MODULES/MEDIA_LIBRARY.md`, `docs/spec/02_ARCHITECTURE/DATA_STORAGE.md`. Решения владельца (2026-10-23): каталог — метаданные Storage; сначала только теги (папки позже); миниатюры 256 px при загрузке; первый этап только картинки (звук позже); удаление из хранилища не делаем, только скрытие.

## Устройство
- Хранилище и подключение Firebase — `core/media.js` (`mediaLoad`, пути `media/…`, `mediaUrl`, заглушки, `mediaKey`). В упражнениях лежат только пути, каталога там нет.
- `core/medialib.js` (`MediaLib`): `list`, `upload`, `update`. Список — рекурсивный `listAll` по `media/`, потом `getMetadata` каждого файла (8 параллельно); миниатюры (`th-…webp`) и звук из списка убираются. Читать список можно без входа (проверено 2026-10-23: правила хранилища пускают `list`), загружать и менять — только вошедшему через Google.
- Файлы библиотеки (картинки; звук — ниже): `media/library/img-<код>.<расширение>` + миниатюра `media/library/th-<код>.webp` (`makeThumb`: canvas, webp 0,82, длинная сторона 256). Миниатюру можно вывести из пути (`thumbPath`). Старые файлы из `media/ex-…/` показываются без миниатюры, с пометкой «упражнение ex-…».
- Метаданные объекта (`customMetadata`): `name` (до 80 знаков), `tags` (через запятую, нижний регистр, до 30 знаков каждый), `w`/`h` (исходные размеры; у старых файлов определяются при показе картинки), `hidden` (`1`). Удаление поля — `null`. Названия и теги правятся без перезаписи файла.
- Подмена обмена с хранилищем для проверки без сети: `MediaLib.backend = { list, upload, update }`.
- Окно: `openMediaLibrary({pick, multi, onPick(items)})` (`core/medialib-ui.js`, стили `core/medialib.css`). Поиск по названию и тегам, фильтры: теги (все выбранные сразу), форма (горизонтальная/вертикальная/квадратная), сортировка, «Скрытые»; свойства файла справа (название, теги, формат, размеры, размер файла, дата, откуда); загрузка нескольких файлов кнопкой или перетаскиванием (новые файлы получают теги, выбранные в фильтре); в режиме выбора — отметки, «Выбрать», двойной щелчок при одиночном выборе.
- Подключено: кнопка «Медиатека» в левой панели редактора (просмотр и правка); `mediaPicker('image', …)` (инструкция и др.) — кнопка «Из медиатеки», загрузка картинок идёт теперь в библиотеку (звук по-прежнему в папку упражнения); Image to Gaps — «Из медиатеки» в панели пропуска (одна картинка) и в «+ Ловушка» (несколько сразу).

## Правила
- Файл никогда не перезаписывается и не удаляется: на него может ссылаться опубликованное упражнение. «Скрыть из списка» только прячет запись. Решение владельца 2026-10-23: удаление не делаем, остаётся скрытие. Если позже понадобится удаление: только файлов, которых нет ни в черновиках браузера, ни в опубликованных `ex-*.json` из репозитория (запрос к GitHub по кнопке), плюс проверить, что правила хранилища разрешают удаление.
- Отсутствующая картинка не роняет ни редактор, ни плеер (в сетке — штриховая заглушка).
- Не проверено на реальном входе: загрузка в `media/library/`, запись метаданных (`updateMetadata`) и миниатюры. Если правила хранилища не пускают запись в `media/library/` или обновление метаданных, текст ошибки показывается в окне.
- Папки (второй этап, 2026-10-23): у файла в метаданных `folder` (название до 40 знаков) и `fcolor` (цвет `#rrggbb` из набора из 8 цветов). Отдельного каталога папок нет: папка существует, пока в ней есть файлы. Только что созданная пустая папка хранится в браузере (`localStorage` `dimvibe.libFolders`) до первого файла. Слева в окне: «Все файлы», «Без папки», папки с цветной точкой и числом файлов, «+ Папка», «Изменить папку» (переименовать, цвет, «Убрать папку» в два нажатия; файлы остаются). Переименование, смена цвета и удаление папки — по одной записи метаданных на каждый файл папки (при отказе хранилища всё возвращается). Файл переносится в папку списком «Папка» в свойствах; загрузка при выбранной папке кладёт новые файлы в неё. Иконки папок и перенос нескольких файлов сразу не сделаны.
- Звук (второй этап): в списке и в окне выбора есть звуки (`media/library/aud-<код>.<расширение>`, без миниатюры; длительность `dur` читается из файла при загрузке; у старых файлов её нет). Переключатель «Всё / Картинки / Звук»; `openMediaLibrary({kind:'audio'|'image'})` показывает один вид и не принимает чужие файлы. Загрузка звука через `mediaPicker('audio', …)` теперь идёт в библиотеку; кнопка «Из медиатеки» есть и у звука (инструкция, озвучка слова и предложения, звук подсказки в Fill Blanks). В карточке звука нота и длительность, в свойствах проигрыватель.
- Дубликаты (2026-10-23, решение владельца: защита при загрузке + кнопка поиска): отпечаток файла — MD5 в base64, тот же, что хранилище пишет в метаданные каждого объекта (`md5Hash`), поэтому старые файлы сравниваются без скачивания и без входа (скачивать файлы из браузера нельзя: у бакета нет CORS). Для нового файла MD5 считает `MediaLib.fileFingerprint` (сверено по четырём эталонным значениям). `MediaLib.upload` до загрузки сравнивает отпечаток со списком (`MediaLib.cache`, при необходимости загружает список); если такой файл уже есть, второй раз не загружает и возвращает запись существующего с `duplicate: true` и `existing`; это работает и для `mediaPicker`, и для окна. Если список недоступен, файл грузится как обычно. Кнопка «Дубликаты (n)» в окне: группы одинаковых нескольких файлов, в каждой отмечен тот, что разумнее оставить (с названием, из библиотеки, в папке, с тегами, самый старый), можно выбрать другой; «Скрыть лишние» в группе или во всех группах (нужен вход). Файлы не удаляются, только скрываются (`MediaLib.duplicateGroups`). Файлы разного вида с одинаковым содержимым дублями не считаются.
- Не сделано: иконки папок, список вместо сетки, фильтры по формату и длительности звука, массовое назначение тегов и массовый перенос, раздел «Настройки → Хранилище», учёт «где используется».
- Не проверено на реальном входе: запись `folder`/`fcolor`/`dur` и загрузка звука (проверено на подмене `MediaLib.backend`).


## Плитка «+» и окно «Добавить изображение / аудио» (2026-10-27, решение владельца по наброску; заменяет два значка ниже)
- Пусто — плитка «+» (`addTile`, 44 px, рамка `--muted`). У `imageControl` с `after: MediaUI.picker('audio', …)` «+» общий: нажатие раскрывает два значка (картинка / звук), щелчок мимо сворачивает; когда одно уже выбрано, «+» сразу открывает окно другого. Пустой звук в паре не рисуется сам (`mbPaired`), о смене сообщает `mbChange`.
- Окно `MediaUI.dialog(kind, {done, onLink, replace, library})`: заголовок «Добавить / Заменить изображение / аудио», кнопка «Медиатека» (закрывает окно, открывает `fromLibrary`; `library:false` её прячет), вкладки «Загрузить своё», «Поиск» (только картинка) и «Сгенерировать» — последние две выключены с пометкой «скоро». Поле-приёмник: нажатие — выбор файла, перетаскивание, Ctrl+V из буфера; без входа Google поле предлагает войти. У картинки с `onLink` — поле «вставьте ссылку на изображение» + «Добавить»: адрес проверяется `safeImageUrl` и пробной загрузкой картинки, в медиатеку не попадает. Esc и щелчок по фону закрывают.
- Миниатюра (`thumb`): чёрный × в правом верхнем углу, ↻ «Заменить» поверх картинки при наведении (на сенсорном экране — маленький значок всегда), 🔗 у ссылки — слева внизу. Звук: чёрная ▶ / ❚❚ (`playButton`) и чёрный ×.
- `MediaUI.pickFile` (сразу выбор файла без окна) оставлен для совместимости.

## Компактная загрузка в редакторах (2026-10-24, вид заменён 2026-10-27)
Выбор и загрузка картинок и звука в редакторах модулей (core/mediabar.js, core/mediabar.css). mediaPicker(kind, get, set, label, opts) в editor.html рисует их для всех модулей (opts.library:false убирает значок медиатеки); MediaUI.imageControl(im, {save, change, after}) — картинка {media, url, alt}; отдельного поля ссылки в модулях нет. Новые модули используют их.
- Без выпадающего списка (решение владельца 2026-10-24): два значка-кнопки (`iconButton`) — «загрузить» сразу открывает выбор файла (без входа Google сначала запускает вход), «из медиатеки» открывает окно медиатеки. Значок = картинка или динамик + маленький знак в правом нижнем углу: стрелка — загрузить, стопка — медиатека (`actIcon(kind, act)`).
- Убрать — крестик × (`removeButton`): в правом верхнем углу миниатюры, у звука — рядом с ▶, у старой неправильной ссылки — в строке предупреждения. Крестик виден, только когда файл выбран. Файл из медиатеки при этом не удаляется.
- Подсказки — обычный `title` браузера, не `data-tip`: длинную подсказку `data-tip` обрезает край узкой колонки. Без входа к подписи добавляется «(сначала вход Google)».

## Картинка по ссылке (2026-10-24, решение владельца)
- Поле ссылки убрано из всех модулей и из блока инструкции: ссылку вводят в окне медиатеки, кнопка «По ссылке» (кроме окна только для звука), а с 2026-10-27 — и в окне «Добавить изображение». Адрес проверяется (`safeImageUrl`, только https), картинка показывается сразу.
- В окне выбора при `openMediaLibrary({link:true})`: «Использовать ссылку» — `onPick([{kind:'image', url, link:true}])`, в медиатеку ничего не пишется; `MediaUI.fromLibrary(kind, done, onLink)` передаёт ссылку в `onLink`. Image to Gaps передаёт `link:true` сам. Без `link` (и в медиатеке из левой панели) — только «Сохранить в медиатеку».
- «Сохранить в медиатеку»: `fetch` картинки → файл JPEG/PNG/WebP с названием из адреса → обычный `uploadFiles` (вход Google, папка, теги, миниатюра, защита от дублей). Работает, только если сайт картинки разрешает скачивание (CORS): Википедия разрешает, многие сайты нет — тогда понятное сообщение «используйте как ссылку или скачайте файл и загрузите». Другие форматы (GIF, SVG) не сохраняются.
- В редакторе у картинки по ссылке на миниатюре значок 🔗; старая неправильная ссылка (не https) показывает предупреждение «выберите картинку заново или уберите».
- Проверено в браузере Claude: меню без пункта ссылки (Multiple Choice, инструкция), неправильный адрес, «Использовать ссылку» в Multiple Choice, инструкции и ловушке Image to Gaps, «Убрать» и отмена, медиатека из левой панели; скачивание с Википедии (fetch) работает, с сайта без CORS — блокируется. **Не проверено:** настоящее «Сохранить в медиатеку» (нужен вход владельца).
