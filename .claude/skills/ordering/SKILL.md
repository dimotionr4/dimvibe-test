# Ordering (девятый модуль)

Спецификация: `docs/spec/04_MODULES/ORDERING.md` (OR-01…OR-04, модуль 08 архива), решения D-064…D-069 в `docs/spec/DECISIONS.md`, приёмка OR-AC-01…18 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-25 («подходят все рекомендации»):
1. До 5 последовательностей в упражнении, все на одной странице друг под другом, у каждой при нескольких — своя необязательная инструкция; проверка общая.
2. Проверка одна, итоговая, как в архиве (D-069): до неё переставлять можно сколько угодно, после — порядок замораживается. Обычные 3/5 проверок с закреплением не используются.
3. После проверки: порядок ученика с ✓ / ✗ на каждом месте (верные зелёные, неверные красные). Подпись «Правильно: …» у неверного места (какой элемент должен там стоять) — только если во вкладке «Поведение» включено «Показывать правильный ответ» (решение владельца 2026-10-25; по умолчанию выключено, в файле `showAnswers: true` только при включённом).
4. Перенос: за ручку ⋮⋮ слева (мышь и палец, на событиях указателя, общий `core/reorder.js`) плюс стрелки ↑↓ справа. Касание карточки вне ручки прокручивает страницу.
5. Вид — только столбиком, с номерами мест. Вида «в строку» не будет (решение владельца 2026-10-25).
6. Картинки и звук (этап 2, сделан 2026-10-25): элемент — текст, картинка или картинка с подписью; у последовательности необязательный звук. В редакторе общие значки: у элемента `MediaUI.imageControl` строкой под полем (миниатюра и значки слева, одной строкой — своя правка CSS `.or-media`), у последовательности «Звук:» `MediaUI.picker('audio')`. В плеере картинка слева от текста (на узком экране текст переносится под неё), лупа увеличения — общая `addZoom`; кнопка «Слушать» над элементами. Просмотр и звук не тратят проверку. «Дизайн»: «Размер картинок» S / M / L (высота 56 / 90 / 140 px, вписана целиком) — только если в упражнении есть картинка. В «Правильно: …» у картинки без текста — маленькая миниатюра. Этап 1 (тоже 2026-10-25) — только текст.
- Лимиты: от 2 до 10 элементов в последовательности (новая — 3 пустых поля), до 5 последовательностей, элемент до 300 символов.

## Что делает ученик
Видит элементы перемешанными, столбиком, у каждого номер места. Тянет за ⋮⋮ (элемент едет за пальцем, соседи раздвигаются, у края окна список прокручивается сам) или жмёт ↑↓. Строка внизу до проверки: «Расставьте элементы по порядку. Проверка одна.» Нажимает «Проверить» один раз — ручки и стрелки исчезают, места окрашиваются, итог «Результат: N из M (%)». Кнопка становится «Начать заново».

## Проверка и баллы
- Единица общего хода — место в последовательности (ID единицы `q1:0`, `q1:1`…): `answer` — ID элемента, который должен там стоять, `value` — ID поставленного (заполняется при проверке).
- 1 балл за каждый элемент на своём месте; считается один раз. Плеер даёт `maxChecks() = 1` и свой `check()` → `{done: true}`.
- «Не заполнено» не бывает: порядок есть всегда.
- Перемешивание: при каждом новом прохождении и «Начать заново»; стартовый порядок никогда не совпадает с правильным (до 20 попыток, потом сдвиг на одно место). Отключить нельзя, ручного стартового порядка нет. В предпросмотре редактора порядок держится, пока набор ID элементов тот же (как у Matching), чтобы карточки не прыгали при правках.
- «Начать заново» без вопроса, пока ученик ничего не двигал (`started()`).

## Редактор
Порядок полей сверху вниз — правильный ответ; перестановка (ручка ⋮⋮ или ↑↓) меняет ответ, отдельного выбора ответа нет. Строка: ручка, номер, поле, выше / ниже / удалить (не меньше 2 полей). «+ Элемент» до 10. Одинаковые элементы в одной последовательности сразу подсвечиваются красной рамкой. При нескольких последовательностях: заголовок «Последовательность N», выше / ниже, копия (новые ID последовательности и элементов), удаление с подтверждением, если не пустая; поле своей инструкции. «Поведение»: «Проверок на прохождение: 1» с пояснением (`fixedChecks` + `fixedChecksNote`; текст пояснения ядро берёт из модуля) и выключатель «Показывать правильный ответ» (`behaviorOptions`, поле `showAnswers`). «Дизайн» — общий, макет с флагом `tf`; своих настроек нет.

## Публикация (validate)
Элемент заполнен, если есть текст или картинка. Ошибки: нет последовательностей; больше 5; меньше 2 заполненных элементов; больше 10; пустой элемент посередине (пустые в конце не ошибка — в файл не попадают); ссылка на картинку не https; одинаковые элементы в одной последовательности — одинаковые и текст (без учёта регистра и лишних пробелов), и картинка (в разных последовательностях можно; та же картинка с разными подписями — разные элементы).

## Файл упражнения
```json
{ "module": "ordering", "format": 1, "showAnswers": true, "imageSize": "m",
  "sequences": [{ "id": "q1", "instruction": "Put the numbers in order", "audio": { "media": "media/…/aud.mp3" },
                  "items": [{ "id": "i1", "image": { "media": "media/…/img.jpg", "alt": "" } },
                            { "id": "i2", "text": "Brush teeth", "image": { "url": "https://…", "alt": "" } },
                            { "id": "i3", "text": "Have breakfast" }] }] }
```
Порядок `items` — правильный порядок. `instruction` пишется только при нескольких последовательностях и если не пустая; `text`, `image` (`media` или `url`), `audio` — только если есть; `imageSize` — только если в упражнении есть картинка. Файлы этапа 1 (только текст) читаются без изменений. ID элементов уникальны во всём упражнении. При загрузке повтор ID получает новый, недостающие элементы — пустые поля.

## Файлы
Перенос за ручку — общий `core/reorder.js` (`Reorder.attach` с классами `or-dragging` / `or-dragging-list`, `Reorder.GRIP`, `Reorder.mix`; им же пользуется Timeline; меняет местами соседей, а не сам элемент, иначе теряется захват указателя; до 2026-10-25 был `modules/ordering/drag.js`). `modules/ordering/`: `editor.js` (`OrderingEditor`), `editor.css`, `player.js` (`OrderingPlayer`), `player.css`. Классы с приставкой `or-`; элементы плеера — `.card.or-item` (Comic рисует им контур), у ручки и стрелок контур Comic скрыт.

## Не проверено
Настоящий палец на телефоне (перетаскивание проверено мышью; у ручки `touch-action:none`), Safari/Firefox, LearnWorlds iframe, настоящая загрузка файлов картинки и звука (нужен вход владельца; показ проверен на файлах из ex-ugfvkv); владельцем — ещё нет.
