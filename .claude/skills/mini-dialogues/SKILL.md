# Mini Dialogues (двадцать третий модуль)

Спецификация: `docs/spec/04_MODULES/MINI_DIALOGUES.md` (MD-01…MD-04), приёмка `MD-AC-01…36` в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md` (сверена только частично). Начат 2026-11-21 по просьбе владельца (ответ «да, давай»: этап 1 — по рекомендации).

## Этап 1 (сделан 2026-11-21): только текст, ввод с клавиатуры
- Упражнение: говорящие (2–6, имя обязательно, сторона «Авто / Слева / Справа»), диалоги (название или сцена необязательны, не меньше двух реплик), реплики (говорящий + текст с пропусками). Пропуск — выделить слово → кнопка «Пропуск» (общий `core/gap-engine.js`); у пропуска ответ, другие верные ответы, подсказка. Лимит 20 пропусков.
- Ответ — только ввод с клавиатуры (`mode: 'typing'` в файле). Банк слов, выпадающий список — этап 2; картинки (аватары), звук реплики и диалога — этап 3; настройки «Дизайна» именно для пузырей (вид, плотность, подпись говорящего, место банка) — этап 4.
- Одна общая проверка на все диалоги, 1 пропуск = 1 балл, проверок 3 (1–5 пропусков) или 5 (6 и больше), «авто» из ядра. Неполный ответ проверку не тратит; верное закрепляется; после последней проверки верный ответ показывается в реплике (`→ ответ`) без баллов. Сравнение — общий `norm()` (регистр, пробелы, конечная точка и знаки).
- Сторона «Авто»: первый говорящий слева, второй справа, дальше по очереди; говорящих отличает имя и значок-инициал, не только цвет и сторона (цвет — `md-c0…5` по номеру говорящего).

## Файлы
`modules/mini-dialogues/`: `editor.js` (`MiniDialoguesEditor`), `editor.css`, `player.js` (`MiniDialoguesPlayer`), `player.css`. Плеер рисует пропуски общей `makeGap(idx)` и `hintButton(idx)` из `index.html`: форма, ширина и нумерация берутся из вкладки «Дизайн» (общие настройки пропусков).

## Формат файла
`{module:'mini_dialogues', format:1, mode:'typing', speakers:[{id,name,side}], dialogues:[{id,title,lines:[{id,speaker,parts:[строка|{gap:ID}]}]}], gaps:{ID:{answer,alternatives,hint}}}`. ID говорящих, диалогов, реплик и пропусков устойчивы (не зависят от текста). Файл не хранит HTML.

## Проверки редактора (`validate`)
Ошибки (блокируют публикацию): нет имени у говорящего; нет диалогов; в диалоге меньше двух реплик; у реплики не выбран говорящий или он удалён; пустая реплика; у пропуска нет ответа; нет ни одного пропуска; больше 20 пропусков. Предупреждения: одинаковые имена говорящих; реплика длиннее 220 знаков; говорящий без реплик. Удаление говорящего оставляет его реплики без говорящего (ошибка до выбора другого).

## Проверено 2026-11-21 (браузер Claude, локальный сервер)
Демо-пример (демо-режим), предпросмотр, создание пропуска выделением, добавление говорящего и реплики, `exportData` → `load` без потерь, проверки и ошибки `validate`, плеер: неполный ответ не тратит проверку, верно / неверно, конец с показом верного ответа, «Начать заново», ширина 375 px без прокрутки вбок, стили Classic, Comic и Экшен (Экшен — пузыри с прямыми углами). **Не проверено:** кнопка «Опубликовать» и загрузка файла, перетаскивание, Safari / Firefox, палец на телефоне, LearnWorlds, светлая тема Экшена, Soft и Fancy, звук и клавиатура (в этапе 1 их нет).
