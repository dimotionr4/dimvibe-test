# Text to Image (двадцатый модуль, подписать картинки словами)

Решения владельца 2026-10-26 («все рекомендации», кроме способов ответа — их три): модуль задуман по образцу владельца (сетка картинок, под каждой пустое окошко, сверху банк слов; в банке использованные слова тускнеют, верное слово в окошке — в зелёной рамке). Не путать: Image to Gaps — картинки в пропусках текста, Label the Diagram — подписи к точкам на одной картинке.

## Что делает ученик
- Сетка картинок, под каждой окошко для слова (общий вид пропуска: форма линия / рамка / плашка / свободная и нумерация из «Дизайна»; ширина окошка всегда по ширине картинки). Три способа ответа, один на всё упражнение, выбирает автор значками в редакторе (поле `mode`), ученик не переключает:
  - `word_bank` (по умолчанию) — банк слов сверху (залипает при прокрутке, не выше 30% экрана, значок «?» с подсказкой): нажать слово, потом окошко, или перетащить (мышью сразу, пальцем после удержания 250 мс; код как в Label the Diagram). Слово в окошке нажатием возвращается в банк. Использованное слово остаётся в банке приглушённым. Новое слово в занятое окошко — прежнее возвращается в банк.
  - `dropdown` — список под картинкой: верные ответы, другие верные и лишние слова, без повторов, перемешаны на прохождение.
  - `typing` — ввод с клавиатуры.
- В конце банк скрыт; если включено «Показывать правильный ответ» (`showAnswers`), под неверным окошком «Правильно: …».

## Проверка и баллы
- Единица общего хода — картинка (`id` карточки), 1 балл. Проверки обычные: 3 при 1–5 карточках, 5 при 6+, автор может выбрать 1–5. Неполный ответ проверку не тратит («Подпишите все картинки: ещё n»), пустые окошки красным пунктиром.
- Проверку делает общий ход `index.html` (своего `check()` у модуля нет): сравнение `norm()` (регистр, пробелы, точка/запятая/?/! в конце не важны); засчитываются слово и «другие верные ответы» этой карточки. Верные закрепляются (✓), неверные остаются (✗) и их можно заменить. Одинаковые слова у разных карточек взаимозаменяемы. Лишние слова не оцениваются, штрафа нет.
- Звука, подсказок и озвучки у карточек нет (этап 1, решение владельца).

## Редактор
Счётчик «Карточек: n/12», значки способа ответа, «?». Карточка: номер, картинка (общий `MediaUI.imageControl`: загрузить / из медиатеки / по ссылке в медиатеке, поля описания нет), «Верное слово», «Другие верные ответы через запятую» (до 5), ↑ ↓ и ×. Блок «Лишние слова» — по одному в строке, до 10. «Дизайн»: размер картинки S / M / L, «Картинка в рамке» (вписать / заполнить) + общие настройки пропуска; новое упражнение создаётся с формой окошка «рамка» (`design.gap.shape: "frame"`). «Поведение»: «Показывать правильный ответ» (по умолчанию выкл). Карточки с одинаковым словом подсвечены жёлтым.

## Публикация (validate)
Ошибки: меньше 2 или больше 12 карточек; у карточки нет слова или картинки; ссылка не https; больше 10 лишних слов. Замечания: одинаковое слово или одна и та же картинка у нескольких карточек; другой верный ответ совпадает со словом другой карточки; лишнее слово совпадает с верным ответом.

## Файл упражнения (format 1)
```json
{ "module": "text_to_image", "format": 1, "mode": "word_bank", "imageSize": "m", "imageFit": "contain", "showAnswers": true,
  "items": [{ "id": "i1", "answer": "plum", "alternatives": ["prune"], "image": { "media": "media/…/img.jpg" } }],
  "distractors": ["pear"] }
```
`mode`: word_bank | dropdown | typing; `imageSize`: s | m | l; `imageFit`: contain | cover; `showAnswers` — только если включено; `alternatives` и `distractors` — только если есть (лишнее слово, равное верному ответу, в файл не попадает). Пустые карточки в файл не попадают. При загрузке: повтор ID получает новый, неверные поля — значения по умолчанию, файл без карточек не открывается («В файле нет карточек.»).

## Файлы
`modules/text-to-image/`: `editor.js` (`TextToImageEditor`), `editor.css`, `player.js` (`TextToImagePlayer`), `player.css`. Классы `ti-` (редактор и плеер), окошко — `.gap.t2i-slot`. Слова банка — `.chip.ti-chip` (Comic рисует контур сам). Версии: editor.js ?v=1, editor.css ?v=1, player.js ?v=1, player.css ?v=1, ASSET_V 98.

## Не проверено
Настоящий палец на телефоне (перенос слов удержанием), Safari/Firefox, LearnWorlds, загрузка своих картинок (демо берёт цифры и дом из медиатеки), тёмная тема плеера (в плеере она всегда светлая), владельцем — ещё нет. Проверено в браузере Claude: создание из `?new=text_to_image`, демо проходит validate, карточки добавить / переместить / удалить, способы ответа в редакторе, вкладки «Дизайн» / «Поведение» / «Публикация», файл туда-обратно, пустой и испорченный файл; плеер во всех трёх способах: неполный ответ не тратит проверку, неверное и верное слово, замена, перенос слова на окошко, «Правильно: …», приём «One.» и «HOME » при вводе, Comic, 375 px без прокрутки вбок, банк залипает при прокрутке. Перетаскивание мышью проверено только по логике (окружение не присылает отпускание кнопки, итоговое действие вызвано вручную).
