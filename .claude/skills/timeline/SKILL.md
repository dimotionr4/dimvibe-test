# Timeline (десятый модуль)

Спецификация: `docs/spec/04_MODULES/TIMELINE.md` (TL-01…TL-04, модуль 11 архива), решения D-083…D-087 в `docs/spec/DECISIONS.md`, приёмка TL-AC-01…22 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`. Родственный модуль — Ordering (skill `.claude/skills/ordering/`): тот же ход «одна итоговая проверка, балл за место» и общее перетаскивание `core/reorder.js`.

Решения владельца 2026-10-25 («все рекомендации»):
1. В упражнении одна хронология (не несколько, как в Ordering).
2. Раздел «Правильная хронология» после проверки — выключатель во вкладке «Поведение» «Показывать правильную хронологию», по умолчанию включён (в файле `showCorrect: false` только при выключенном).
3. Вид — вертикальная линия с точками: слева дата, точка на линии, справа карточка события. На узком экране (до 480 px) дата над карточкой. Пока даты скрыты, колонки даты нет.
4. Стартовый порядок никогда не совпадает с правильным (как в Ordering; в архиве совпадение допускалось).
5. Этап 1 (2026-10-25) — дата, текст события, пояснение. Этап 2 (тоже 2026-10-25) — у события необязательные картинка и звук. Содержимое события — текст и (или) картинка; при картинке текст — подпись. В редакторе строкой под полями общие значки `MediaUI.imageControl` с `after:` звуком `MediaUI.picker('audio')` (миниатюра и значки одной строкой слева — правка CSS `.tl-media`). В плеере картинка слева от текста с лупой `addZoom`, кнопка 🔊 в карточке; то же в «Правильной хронологии». Просмотр и звук не тратят проверку и не двигают событие. «Дизайн»: «Размер картинок» S / M / L (56 / 90 / 140 px) — только если есть картинка.
6. Лимиты: от 2 до 12 событий (новое упражнение — 3 пустых), дата до 40 символов, текст до 300, пояснение до 400.

## Что делает ученик
Видит события перемешанными на линии, без дат (или с датами, если автор выбрал «Даты видны: Сразу»). Тянет за ⋮⋮ (событие едет за пальцем, у края окна список прокручивается сам) или жмёт стрелки «Раньше / Позже». Строка внизу до проверки: «Расставьте события по порядку. Проверка одна.» После «Проверить»: заголовок «Ваша хронология» — порядок ученика, открыты все даты, точки и карточки зелёные с ✓ или красные с ✗; ниже, если включено, «Правильная хронология» — все события по порядку автора, с датами и пояснениями. Итог «Результат: N из M (%)», кнопка «Начать заново».

## Проверка и баллы
- Единица общего хода — место на линии (ID `p0`, `p1`…): `answer` — ID события, которое должно там стоять, `value` — ID поставленного (заполняется при проверке). 1 балл за событие на своём месте, считается один раз. Плеер даёт `maxChecks() = 1`, свой `check()` → `{done: true}`, `status()` до проверки, `started()`.
- Даты ни на что не влияют: порядок задаёт автор, ничего не сортируется и не распознаётся.
- Перемешивание — `Reorder.mix` (`core/reorder.js`); в предпросмотре порядок держится, пока набор ID тот же.

## Редактор
Одна строка на событие: ручка ⋮⋮, номер, поле «Дата» (жирное, узкое), поле события, выше / ниже / копия (новый ID, сразу под оригиналом) / удалить (не меньше 2); строкой ниже — пояснение. Порядок сверху вниз — правильный ответ. Сразу подсвечиваются: красным — карточки, одинаковые для ученика; жёлтым — одинаковые даты. «Дизайн»: «Даты видны» — После проверки (по умолчанию) / Сразу (`dateVisibility`). «Поведение»: «Проверок на прохождение: 1» с пояснением (`fixedChecks`, `fixedChecksNote`) и «Показывать правильную хронологию».

## Публикация (validate)
Ошибки: меньше 2 событий; больше 12; пустое событие посередине (пустые в конце не попадают в файл); нет даты; нет ни текста, ни картинки; ссылка на картинку не https; две карточки одинаковы для ученика — сравнивается то, что видно до проверки: текст (без учёта регистра и лишних пробелов) и картинка, при видимых датах ещё и дата (звук не различает). Предупреждение (не мешает публикации): одинаковые даты.

## Файл упражнения
```json
{ "module": "timeline", "format": 1, "dateVisibility": "always_visible", "showCorrect": false, "imageSize": "m",
  "events": [{ "id": "e1", "date": "1914", "text": "World War I begins", "explanation": "…" },
             { "id": "e2", "date": "1939", "image": { "media": "media/…/img.jpg", "alt": "" }, "audio": { "media": "media/…/aud.mp3" } }] }
```
Порядок `events` — правильный порядок. `dateVisibility` пишется только при «Сразу», `showCorrect` — только при выключенном; `text`, `image` (`media` или `url`), `audio`, `explanation` — только если есть; `imageSize` — только если есть картинка. Файлы этапа 1 читаются без изменений. При загрузке повтор ID получает новый, недостающие события — пустые.

## Файлы
`modules/timeline/`: `editor.js` (`TimelineEditor`), `editor.css`, `player.js` (`TimelinePlayer`), `player.css`. Классы с приставкой `tl-`; карточки плеера — `.card.tl-ev` (Comic рисует контур), у ручки и стрелок контур Comic скрыт. Перетаскивание — общий `core/reorder.js` (`Reorder.attach`, `Reorder.GRIP`, `Reorder.mix`).

## Не проверено
Настоящий палец на телефоне (перетаскивание проверено мышью), Safari/Firefox, LearnWorlds iframe, настоящая загрузка файлов картинки и звука (нужен вход владельца; показ проверен на файлах из ex-ugfvkv); владельцем — ещё нет.
