# True / False (верно / неверно) — третий модуль

Спецификация: `docs/spec/04_MODULES/TRUE_FALSE.md` (D-035…D-040, TF-AC-01…16). Решения владельца 2026-10-23: показ «по одному» по умолчанию, переключается на «списком» (во вкладке «Дизайн»); пресеты только на английском; картинок к утверждениям нет (картинка только в общей инструкции); 1 балл за утверждение; число проверок «авто» (1–5 вручную); лимит 10 утверждений (в спецификации лимит не задан).

## Что общего с остальными модулями
Вкладки, инструкция, цвет, Classic/Comic, макет, кнопка «Проверить», число проверок, закрепление верных, «Начать заново», публикация — общее ядро. Каждое утверждение работает в `index.html` как «пропуск» общего хода (`TrueFalsePlayer.units()`: `answer` — верная категория `a|b|c`, `value` — выбранная). Развилка `isTF()` в `index.html` (`build`, `shuffleWords`, `render`, `check` — текст про неполный ответ, `restart`). Подсказок (замок/лампочка) у модуля нет. Нет вида текста: в окне создания у True / False одна кнопка «Создать упражнение» (`#kindGo`).

## Формат файла (format 1)
```json
{ "id":"ex-…", "module":"true_false", "format":1, "view":"one",
  "answers": {"preset":"tf","a":"True","b":"False","c":"Not stated"},
  "items": [{"id":"q1","text":"…","correct":"a","explanation":"…","audio":{"media":"media/…"},"answers":{…}}] }
```
- Категории `a`, `b`, необязательная `c` (есть `c` в `answers` — третья включена). ID не зависят от подписей. `correct` хранит ID, поэтому смена пресета и переименование не двигают правильный ответ.
- `answers` на верхнем уровне — общий формат; `items[i].answers` — индивидуальный (в файле уже готовые подписи). `preset`: `tf` True/False, `fo` Fact/Opinion, `fi` Formal/Informal, `sd` Safe/Dangerous, `hu` Healthy/Unhealthy, `pp` Past/Present, `custom`.
- `view`: `one` (по умолчанию) или `list`.
- Черновик: `answers`/`items[i].fmt` = `{preset, a, b, c, third}` (поля `a`,`b` нужны только для custom; `c` и `third` хранятся и когда третья отключена), `items[i]` = `{id, text, correct, explanation, audio (путь), override, fmt}`. Выключение «Другой формат ответов» не стирает `fmt`.

## Редактор (`modules/true-false/editor.js`, `editor.css`)
Блок «Варианты ответов» (пара, Custom, третий вариант, «Require correction if False» — неактивный, «Coming soon», в плеере и файле не участвует), строки утверждений (раскрываются по одной: текст, правильный ответ, пояснение, озвучка из медиатеки, «Другой формат ответов»), добавить/дублировать (новый ID)/удалить (заполненное — подтверждение прямо в строке, без `confirm()`)/вверх-вниз/перетаскивание. После смены формата у строк с выбранным ответом метка «Проверьте правильный ответ» (только напоминание, `recheck` в памяти, не в черновике). `designOptions` — «Показ утверждений». Хук модуля `unitCount(draft)` даёт ядру (`renderBehavior`) число утверждений для «авто» в «Поведении». В макете «Дизайн» вместо пропуска рисуются две кнопки (`c.tf` в `designMock`).

## Публикация
Ошибки: нет утверждений или больше 10; пустой текст; не выбран ответ; ответ `c` при отключённой третьей (назначение не стирается, публикация блокируется); пустые или совпадающие (без регистра и крайних пробелов) подписи включённых категорий (общие — если ими пользуется хотя бы одно утверждение — и индивидуальные). Замечание: формат менялся, проверьте ответ.

## Плеер (`modules/true-false/player.js`, `player.css`)
- «По одному»: ряд номеров (отметки ✓/✗, текущий выделен) и «Предыдущее / Следующее», переход свободный, выбор сохраняется; «списком» — все карточки подряд. Одно утверждение — всегда карточка без навигации.
- Проверка идёт по всем утверждениям сразу и только когда все отвечены (иначе проверка не тратится, в режиме «по одному» открывается первое пустое). Верные закрепляются (кнопки блокируются), неверные можно менять до конца. Результат не только цветом: ✓ и ✗ на выбранной кнопке.
- Пояснение скрыто до проверки; открывается у закреплённых (верных) и у всех после завершения; неверные скрыты до успешного исправления или конца. «Начать заново» снова скрывает. Баллы и проверки не трогает.
- Звук утверждения: значок динамика у текста (`audioButton`), без ограничений.
- Не сделано: Require correction if False (по спецификации); пояснения-шпаргалки не показывают верный ответ.
