# Essay Writing (четырнадцатый модуль)

Спецификация: `docs/spec/04_MODULES/ESSAY_WRITING.md` (модуль 16 архива, EW-02…EW-04, решения D-108…D-111), приёмка EW-AC-01…36 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`. Архив рассчитан на сервер (отправка работы, оценка преподавателя по рубрике, строгий режим); у нас сервера нет, поэтому сделана только часть «Practice» архива.

Решения владельца 2026-10-25 («все рекомендации»):
1. Текст ученика преподавателю **не отправляется**: кнопка «Скопировать текст» (ученик вставляет его туда, где курс принимает работы). Отправка через внешнюю форму — возможное улучшение позже.
2. Считается автоматически: слова (от и до), абзацы (от и до), обязательные слова и фразы (с числом употреблений и формами), запрещённые слова и фразы. Предложения не считаем (подсчёт неточный: *Dr.*, *e.g.*). Качество текста, грамматику и смысл программа не оценивает, ИИ нет.
3. У каждого условия пометка «Обязательно» / «Совет»; ученик видит их двумя группами. Строгого режима (блок отправки) нет, писать ничего не мешает.
4. Образец ответа (открывается кнопкой «Образец ответа») и список «проверь себя» (галочки без баллов) — необязательные.
5. Баллов нет, итог — «Обязательных условий: X из N · Советов: A из B» в нижней строке (по показанному заданию при «по одному», по всем при «все сразу»; без условий — «Слов: n»). Это не оценка.
6. Исключение из общего правила «прохождение не сохраняется» (CLAUDE.md, раздел 3, п. 6): текст и галочки «проверь себя» хранятся в `localStorage` ученика (ключ `dimvibe-essay:<id упражнения>`), чтобы обновление страницы не стёрло работу. «Начать заново» (↻, с вопросом, если что-то написано) стирает всё. Если браузер хранение запрещает — предупреждение «скопируйте текст». В предпросмотре редактора черновик не сохраняется, текст держится между пересборками.
7. До 5 заданий; показ «По одному заданию» (по умолчанию) или «Все задания сразу» — настройка во «Дизайне» (`view`).
8. Картинки и звук — этап 2 (ещё не сделан; общие `MediaUI.imageControl` / `MediaUI.picker`).

## Что делает ученик
Читает тему и задание, пишет в поле (до 20 000 символов, набор не блокируется при выходе за границы), под полем видит «Слов: n · Абзацев: m» и список условий: ✓ выполнено, ✗ нарушено (слов больше максимума, запрещённое слово найдено), ○ ещё не выполнено (не только цветом). Пустой или из одних пробелов текст не выполняет ни одно условие. Кнопка «Проверить» скрыта (`instant() = true`), проверок нет.

## Правила счёта (`modules/essay-writing/analysis.js`, `EssayText`)
- Слово: буквы и цифры (Unicode); внутри слова допустимы апостроф и дефис («don't», «well-known»); числа считаются словами; регистр и вид апострофа не важны; NFC.
- Абзац: блок текста между пустыми строками (пустая строка — перенос + перенос; одинарный Enter абзац не создаёт). Пробелы-только блоки не считаются.
- Обязательное и запрещённое ищутся по целым словам («art» не найдётся в «smart»); фраза — слова подряд, лишние пробелы и знаки между ними не мешают; формы («go» → goes, going, went) преподаватель перечисляет сам, программа их не угадывает; на каждом месте берётся самый длинный подходящий вариант, вхождения не пересекаются.
- Общий для редактора и плеера; `evaluate(task, text)` → `{words, paras, empty, conds:[{id, level, state: ok|bad|todo, text}]}`.

## Редактор
Задание — блок: «Задание N», выше / ниже / копия (новые ID всех условий и пунктов) / удаление (с вопросом, если заполнено). Поля: тема (необязательно), задание (обязательно). «Условия»: слов и абзацев «от — до» и важность; «Нужно использовать» (слово или фраза, формы через запятую, «раз», важность; до 10); «Нельзя использовать» (до 10). «Образец и проверь себя»: образец (до 5000 символов) и до 8 пунктов. Лимиты: слов ≤ 5000, абзацев ≤ 30, раз ≤ 20, тема 100, задание 1500, слово 60, формы 200. Вкладка «Поведение» показывает «Проверок нет» (`noChecks` в модуле — общий крючок `editor.html`). «Дизайн»: «Показ заданий». Макет — общие кнопки (флаг `tf`); настройка «Кнопка «Проверить»» в макете для этого модуля бессмысленна (кнопки нет).

## Публикация (validate)
Ошибки: нет заданий; больше 5; не написано задание; слов или абзацев «от» больше «до»; максимум 0; абзацев не меньше N, а слов не больше M меньше; слово без единого слова/буквы; обязательное требует больше слов, чем разрешено всего; одно и то же нужно и запрещено (в том числе запрещённое слово внутри обязательной фразы). Предупреждение: слово записано дважды. Пустые поля не ошибка — в файл не попадают.

## Файл упражнения
```json
{ "module": "essay_writing", "format": 1, "view": "list",
  "tasks": [{ "id": "t1", "topic": "My weekend", "prompt": "Write about…",
              "words": { "min": 50, "max": 120 }, "paras": { "min": 2, "max": 4, "level": "advisory" },
              "terms": [{ "id": "r1", "text": "because", "min": 2 }, { "id": "r2", "text": "go", "forms": ["goes", "went"], "level": "advisory" }],
              "banned": [{ "id": "b1", "text": "very" }],
              "sample": "…", "checklist": [{ "id": "c1", "text": "Я объяснил, почему…" }] }] }
```
`view` — только «list»; `topic`, `words`, `paras`, `terms`, `banned`, `sample`, `checklist` — по наличию; `level` — только «advisory»; `forms` — по наличию; `min` у слова — только если больше 1. ID заданий, условий и пунктов уникальны; при загрузке повтор получает новый.

## Файлы
Версии: `analysis.js` ?v=1, `editor.js` ?v=1, `editor.css` ?v=1, `player.js` ?v=2, `player.css` ?v=1, ASSET_V 73. `modules/essay-writing/`: `analysis.js` (`EssayText`), `editor.js` (`EssayWritingEditor`: create, demo, render, load, exportData, validate, unitCount, noChecks, noChecksNote, designOptions, behaviorOptions), `editor.css`, `player.js` (`EssayWritingPlayer`: units (пустой), reset, started, status, instant, render), `player.css`. Классы с приставкой `ew-`; карточка `.card.ew-card` (line-height 1.5); номера и «Предыдущее / Следующее» — `tf-dots`, `tf-pager`. Поле ввода обновляет счётчики на месте (`refresh`), не пересобирая карточку; нижняя строка — `updateStatus()` с задержкой 80 мс. Подписи кнопок не меняются (в Comic смена текста стирает контур): результат копирования — отдельная строка `.ew-copied`.
