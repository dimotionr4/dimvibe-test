# Splice (пятнадцатый модуль, этап 1 — только текст)

Спецификация: `docs/spec/04_MODULES/SPLICE.md` (SP-01…SP-04, приёмка SP-AC-01…30 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`), решение D-098 в `docs/spec/DECISIONS.md`. Детали редактора в архиве — только предложения; решения владельца ниже важнее.

Решения владельца 2026-10-26 («все рекомендации»):
1. Этап 1 — оба режима, текст. Картинки и звук — этап 2. Перетаскивание мышью добавлено 2026-10-26 по просьбе владельца (см. «Перенос мышкой»); пальцем — нажатие.
2. Слово пишется с косыми чертами: `mo/dern/ize`. Кнопки «Авто 2 / 3 / 4» расставляют черты поровну по графемам (`Intl.Segmenter`) и честно считаются техническим, не слоговым делением; «Склеить» убирает черты. Без черты слово не годится (меньше 2 частей).
3. Вид частей — «Плитки» и «Бумажные кусочки» (настройка «Дизайна» `tokenStyle`: tiles / paper).
- Лимиты (выбраны мной, в архиве их нет): до 10 слов, в слове 2–8 частей, в мозаике всего до 40 частей, слово до 60 символов, в мозаике не меньше 2 слов.

## Режимы (один на всё упражнение, выбирает преподаватель: `mode`)
- **Одно слово** (`single`): у каждого слова свой банк; нажатие по части — в конец слова, по части в слове — назад в банк. Показ «по одному / все сразу» — настройка «Дизайна» `view`. Подсказка — открывает ученик, пояснение — после проверки.
- **Мозаика** (`mosaic`): окошко на каждое слово и один общий банк. Нажатие на окошко делает его активным, часть из банка кладётся в активное; в Easy / Medium заполненное окошко передаёт ход следующему со свободным местом, в Hard окошко не ограничено. Нажатие на часть в окошке — назад в банк (переносить между окошками — через банк).
  - **Easy**: видны название слова (поле «Название», иначе «Слово N») и число частей; верно, только если слово собрано в своём окошке.
  - **Medium** (по умолчанию): «Слово N», число частей видно; слово засчитывается в любом окошке с тем же числом частей и тем же текстом.
  - **Hard**: «Слово N», числа частей нет; в каждом окошке не меньше 2 частей; засчитывается любое окошко с правильным текстом.
  - Medium и Hard сравнивают с **мультимножеством** заданных слов (повторы считаются столько раз, сколько заданы). Одинаковые части взаимозаменяемы. Подсказки в мозаике нет (она выдала бы слово).

## Картинка и звук (этап 2, 2026-10-26)
У слова необязательные картинка и звук **задания** (отдельная озвучка слов / частей не нужна — решение владельца). Редактор: строка «Картинка, звук» под частями — общие `MediaUI.imageControl` с `after:` `MediaUI.picker('audio')`. Плеер: картинка над словом с лупой `addZoom`, под ней «Слушать» (`audioButton`); они не тратят проверку и не трогают части. «Размер картинок» S / M / L (110 / 180 / 260 px) — настройка «Дизайна», только если есть картинка. В мозаике картинка и звук видны **только на Easy** (в окошке своего слова); на Medium и Hard по умолчанию скрыты (выдали бы, какое слово где собирать), автор может показать их выключателем «Поведения» «Картинка и звук в мозаике Medium / Hard» (`mediaAlways: true` в файле, решение владельца «по выбору») — редактор пишет об этом под строкой. Нажатие на картинку и звук не выбирает окошко. Файл: `image` {media | url, alt}, `audio` {media} у слова, `imageSize` — только если есть картинка. Копия слова — глубокая.

## Перенос мышкой (2026-10-26)
Кроме нажатия, части переносятся мышью (HTML5 drag-and-drop, `draggable` на частях). Из банка — в слово/окошко на выбранное место (по положению курсора среди частей); внутри слова — перестановка; между окошками мозаики; бросить на пустое место карточки — вернуть в банк. В окошко Easy / Medium, где нет свободного места, часть не принимается (остаётся на месте). После проверки не работает. На телефоне HTML5-перенос не срабатывает — там нажатие (перенос пальцем не делали). В Firefox перетаскивание кнопок может не работать — не проверено.

## Проверка и баллы
Одна итоговая на всё упражнение (`maxChecks() = 1`, `fixedChecks`). Пока не все части использованы (в мозаике — все разложены, окошки Easy / Medium заполнены, в Hard ≥ 2 частей) — проверка не тратится: «Используйте все части: в банке осталось N» и т. п., пустые окошки с красной рамкой. 1 балл за слово, без баллов за часть. Сравнение — Unicode NFC, регистр и знаки важны. После проверки части не двигаются; ✓ / ✗; «Правильно: mo · dern · ize» (одно слово) или блок «Правильные слова» с пояснениями (мозаика) — выключателем «Показывать правильный ответ» (по умолчанию включён). Единицы общего хода — слова (`units()`), в мозаике слово k ↔ окошко k.

## Файл упражнения
```json
{ "module": "splice", "format": 1, "mode": "mosaic", "level": "easy", "tokenStyle": "paper", "showAnswers": false,
  "tasks": [{ "id": "t1", "answer": "mo/dern/ize", "label": "сделать современным", "explanation": "…" }] }
```
Для одного слова: `view: "list"` (только при «Все сразу»), `hint` вместо `label`. `mode` пишется только у мозаики, `level` — только если не medium, `tokenStyle` — только paper, `showAnswers` — только при выключенном; `label` — только у мозаики, `hint` — только у одного слова, `explanation` — если есть. Части лежат в `answer` между чертами.
