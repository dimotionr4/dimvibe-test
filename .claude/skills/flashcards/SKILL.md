# Flashcards (двадцать второй модуль)

Спецификация: `docs/spec/04_MODULES/FLASHCARDS.md` (FC-01…FC-04, модуль 17 архива), приёмка FC-AC-01…32 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-27 (этап 1, «все рекомендации»):
1. Это **самооценка, не задание**: нет баллов, проверок, попыток, таймера и итоговой оценки. «Знаю» / «Повторить» — слова ученика о себе.
2. Этап 1: только текст (лицевая, обратная, подсказка), одно направление «лицевая → обратная». **Позже:** обратное направление с отдельным прогрессом, картинка и звук на сторонах, вставка списком (TSV/CSV), размер Compact / Standard, перетаскивание карточек за ручку (пока кнопки «выше / ниже»).
3. Три режима: «Просмотр» (листать, переворачивать, считается число просмотренных), «Проверка» (по умолчанию: перевернуть → «Знаю» / «Повторить», кнопки недоступны до переворота), «Повтор» (только «Повторить»).
4. Порядок: «Перемешать» (по умолчанию) или «По порядку» — выбор во вкладке «Дизайн». Внутри прохождения порядок стабилен, «Начать заново» (↻) перемешивает заново и сбрасывает оценки.
5. Переворот: «Поворот» (3D, по умолчанию) или «Появление»; при системной настройке «уменьшить анимацию» анимации нет.

## Формат файла
`{module: 'flashcards', format: 1, order?: 'fixed', anim?: 'fade', cards: [{id, front, back, hint?}]}`
- ID карточки (`c1`, `c2`…) устойчив: не зависит от текста и места. Копия получает новый ID.
- `order` пишется только `fixed`, `anim` — только `fade` (иначе перемешать и поворот).
- Лимит: карточек до 100. Пустые карточки в файл не попадают.

## Проверка и публикация
- Ошибки: нет карточек; пустая карточка; не заполнена лицевая или обратная сторона.
- Предупреждения: одинаковые карточки (не блокируют), в колоде одна карточка.
- `unitCount` = число карточек, `noChecks` = true.

## Как работает в общем плеере
- Как у Vocabulary: `units()` пуст, `instant()` true, `noFooter()` true (нижней панели нет).
- Переворот не перерисовывает страницу (иначе нет анимации): на карточке переключается класс `fc-flipped`. Невидимая сторона получает `aria-hidden`.
- «Проверка»: оценка карточки перезаписывает прежнюю (двойного счёта нет); после оценки показывается ближайшая неоценённая; когда оценены все — итог с кнопками «Повторить непонятные» и «Пройти ещё раз».
- «Повтор»: очередь — снимок карточек «Повторить» на начало круга; каждая карточка в круге один раз, даже если её отметили «Знаю»; оценка влияет на следующий круг. В конце круга — «Ещё круг», если «Повторить» остались.
- Подсказка видна только пока карточка лежит лицевой стороной.
- Оценки, просмотренные и очередь живут только в открытой странице (правило «прохождение не сохраняется», раздел 3 CLAUDE.md).
- Демо: `FlashcardsEditor.demo` (четыре карточки, у двух подсказка).
