# Odd One Out (тринадцатый модуль)

Спецификация: `docs/spec/04_MODULES/ODD_ONE_OUT.md` (OO-01…OO-04, модуль 05 архива), решения D-046…D-050 в `docs/spec/DECISIONS.md`, приёмка OO-AC-01…16 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-25 («подходят все рекомендации»):
1. Показ групп — настройка «Показ групп» во вкладке «Дизайн»: «По одной группе» (по умолчанию, номера сверху и «Предыдущая / Следующая») или «Все группы сразу» (с подписями «Группа N»). Выбор сохраняется при переходе.
2. Вид элементов — одна настройка «Вид элементов» на всё упражнение: «Плашки» (по умолчанию, в строку с переносом) или «Карточки» (сетка `auto-fill, minmax(130px, 1fr)`). Индивидуального вида у группы (из архива) нет — можно добавить позже, если понадобится.
3. Неверный выбор после промежуточной проверки остаётся на месте с ✗; ученик сам выбирает другой (новый выбор снимает пометку).
4. «Показывать правильный ответ» — выключатель во вкладке «Поведение», по умолчанию выключен (как в Ordering, Timeline, Categories). Если включён, после конца в неверной группе лишний элемент — зелёный пунктир и ✓. До конца правильный ответ не раскрывается.
5. Лимиты: в группе 3–8 элементов (новая группа — 3 пустых поля), групп до 20, элемент до 100 символов, задание группы до 200.
6. «Перемешивать элементы» — выключатель в «Поведении», по умолчанию включён. Новое перемешивание при открытии и «Начать заново»; внутри прохождения порядок стабилен; в предпросмотре редактора порядок держится, пока набор ID элементов группы тот же.
7. Картинки и звук — **этап 2** (ещё не сделан): элемент — текст, картинка, картинка с подписью, необязательный звук у элемента, лупа `addZoom`; как в Categories — элементы «только картинка» / «только звук» с галочкой «Спрятать текст» (текст показывается после конца), карточка «только звук» с номером «Звук N». В редакторе — только `MediaUI.imageControl` / `MediaUI.picker` (`core/mediabar.js`). Элемент плеера уже сделан блоком `div` (не кнопкой), чтобы внутрь встали кнопки лупы и звука.

## Что делает ученик
В карточке группы — задание группы (жирным) или по умолчанию «Найдите лишнее.», под ним элементы. Нажатие выбирает элемент, нажатие на другой меняет выбор, повторное нажатие на выбранный снимает выбор (до закрепления). Перетаскивания нет.

## Проверка и баллы
- Единица общего хода — группа: `answer` — ID лишнего элемента, `value` — ID выбранного; 1 балл за группу.
- Проверка общая (`index.html`): нужен выбор во всех группах, иначе проверка не тратится, группа без выбора — красная пунктирная рамка (`.oo-card.missing`, добавлен в поиск первой незаполненной в `check()`), при «по одной» показывается первая такая группа.
- Число проверок общее: 3 при 1–5 группах, 5 при 6+, автор выбирает 1–5.
- Верная группа закрепляется (зелёный, ✓); неверный выбор — красный с ✗.
- Пояснение группы — после верного ответа или в конце; при ошибке до исправления не показывается.

## Редактор
Каждая группа — блок: «Группа N», выше / ниже / копия (новые ID группы и элементов, отметка лишнего переходит на копию того же элемента) / удаление (с вопросом, если группа не пустая; последняя группа заменяется пустой). Поле задания группы, строки элементов: кружок слева — отметить лишний (ровно один, хранится ID), поле, выше / ниже / × (не меньше 3 полей). Удаление лишнего снимает отметку и пишет сообщение «отметьте новый лишний». «+ Элемент» до 8. Одинаковые элементы в группе подсвечиваются жёлтым. Пояснение (необязательно). «Дизайн»: «Показ групп» (`view`), «Вид элементов» (`look`); макет — общие кнопки ответа (флаг `tf`).

## Публикация (validate)
Ошибки: нет групп; больше 20; в группе меньше 3 заполненных элементов или больше 8; не отмечен лишний или он пустой. Предупреждение (публикацию не блокирует, архив OO-AC-15): одинаковые элементы в группе. Пустые поля элементов не ошибка — в файл не попадают.

## Файл упражнения
```json
{ "module": "odd_one_out", "format": 1, "view": "list", "look": "cards", "shuffle": false, "showAnswers": true,
  "groups": [{ "id": "g1", "prompt": "Что не фрукт?",
               "items": [{ "id": "i1", "text": "apple" }, { "id": "i2", "text": "banana" }, { "id": "i3", "text": "carrot" }],
               "odd": "i3", "explanation": "Carrot — овощ." }] }
```
`view` пишется только при «list», `look` — только при «cards», `shuffle` — только выключенное, `showAnswers` — только включённое; `prompt` и `explanation` — только если не пустые. ID элементов уникальны во всём упражнении. При загрузке повтор ID получает новый (отметка лишнего переходит вместе с ним), `odd` на несуществующий элемент — пустой (ошибка публикации), у группы меньше 3 элементов — добавляются пустые поля.

## Файлы
Версии: `editor.js` ?v=1, `editor.css` ?v=1, `player.js` ?v=1, `player.css` ?v=1, ASSET_V 70. `modules/odd-one-out/`: `editor.js` (`OddOneOutEditor`: create, demo, render, load, exportData, validate, unitCount, designOptions, behaviorOptions), `editor.css`, `player.js` (`OddOneOutPlayer`), `player.css`. Классы с приставкой `oo-`; элемент плеера — `div.oo-item` с классом `.chip` (Comic: овальный контур) или `.card` (прямоугольный) по «Виду элементов»; стили — `:is(.chip, .card).oo-item`, потому что общие `.chip` и `.card` из `index.html` заданы позже. Номера групп и «Предыдущая / Следующая» — `tf-dots`, `tf-pager` (CSS True / False).
