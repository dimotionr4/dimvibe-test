# Image to Gaps (картинки в пропусках) — второй модуль

Подробная спецификация: `docs/spec/04_MODULES/IMAGE_TO_GAPS.md` (решения D-029…D-034). Важно: по спецификации в пропуски ставятся **картинки**, а не слова на областях картинки (вариант «слова на картинке» из `docs/MODULE_NOTES.md` — отдельный будущий модуль, не этот). Решение владельца 2026-10-23: вариант А (картинки в пропусках, текст с пропусками как в Fill Blanks).

## Что общего с Fill Blanks
- Текст с пропусками (предложения или связный текст, лимит 10) — общий движок `core/gap-engine.js` (`GapEngine`): `fromSelection`, `restoreText`, `readDom`, `nextId`, `gapOrder`. Движок знает только текст и ID пропусков; ответы, картинки и банк — в модулях. Fill Blanks тоже пользуется им (вынесено 2026-10-23, проверено: создание пропуска, плеер, Undo).
- Общие: вкладки Содержимое/Дизайн/Поведение/Публикация, инструкция, цвет, Classic/Comic, форма пропуска (линия, рамка, плашка, свободная; для картинки плашка и свободная форма — скруглённые прямоугольники), нумерация, макет, кнопка «Проверить», число проверок, ход прохождения (неполный ответ проверку не тратит, верные закрепляются ✓, неверные редактируются ✗, конец, «Начать заново»).
- Один способ ответа: банк картинок (нажать картинку, потом пропуск). Режимов «ввод/список» нет; кнопки режимов в предпросмотре скрыты (`body.no-modes`).

## Формат файла (format 1)
```json
{ "id": "ex-…", "module": "image_to_gaps", "format": 1, "layout": "sentences", "items": [{"id":"s1","parts":["The ",{"gap":"g1"}," is red."]}],
  "gaps": {"g1": {"image": {"stub":"apple","alt":"apple"}}},
  "distractors": [{"stub":"fish","alt":""}],
  "imageSize": "m", "imageFit": "contain" }
```
- Картинка (`gaps[id].image`, элемент `distractors`): `{media | stub | url, alt}` — путь в хранилище `media/…` (загрузка через `mediaPicker`), заглушка из `core/stubs/<имя>.svg` (набор `MEDIA_STUBS` в `core/media.js`) или внешняя ссылка `https://`. Приоритет: media, stub, url. `alt` по умолчанию — выделенное слово.
- `imageSize`: `s` | `m` (по умолчанию) | `l`; ориентиры в плеере S 64×54, M 88×72, L 120×96 px (спецификация даёт 76×64 / 108×88 / 146×116; уменьшено по просьбе владельца «не громоздкие», на экране до 420 px ещё меньше). `imageFit`: `contain` (по умолчанию) | `cover`. Пока лежат в «Содержимом» (строка над текстом), по спецификации должны быть в «Дизайне» — перенести.
- Банк в плеере: по одной карточке на каждый пропуск (одна картинка в двух пропусках — две карточки) плюс ловушки; порядок перемешивается один раз на прохождение.
- Оценка: по идентичности картинки `mediaKey()` (`m:`, `s:` или `u:` + источник), а не по карточке: любая карточка с правильной картинкой верна. 1 балл за пропуск. ID карточек ученик не видит.
- Черновик: у пропуска `{word, image:{media,url,stub,alt}}`, ловушки `{id, image}`; `word` — выделенное слово (возвращается в текст при удалении пропуска, подсказка для alt).

## Публикация
Ошибки: нет пропусков, больше 10, у пропуска нет картинки или ссылка не `https://`. Замечания: ловушка совпадает с верной картинкой пропуска, нет ловушек.

## Плеер (`modules/image-to-gaps/player.js`, `player.css`)
- Общий ход прохождения в `index.html` (переменные `data, gaps, selected, finished, note, bankOrder`), развилка `isImg()` в `build`, `shuffleWords`, `makeGap`, `renderBank`. Модуль даёт `ImageToGapsPlayer.gap/shuffle/makeGap/renderBank`.
- Нажатие на картинку подсвечивает все пустые пропуски одинаково (`.target`), нажатие на пустой пропуск ставит картинку; на заполненный без выбора — возвращает; с выбранной новой — заменяет (прежняя возвращается). Использованная карточка остаётся на месте приглушённой. Esc, повторное нажатие на карточку и щелчок мимо снимают выбор. Клавиатура: Tab, Enter/Пробел; фокус возвращается на тот же элемент после перерисовки.
- Не сделано: перетаскивание (второй способ, ITG-02 A), «Заменить во всех пропусках» (ITG-04 C), показ верных картинок после завершения (ITG-04 D), подсказки и озвучка, общая медиатека (следующий пункт плана владельца), закреплённая панель банка на телефонах (ITG-02 D не утверждено).

## Редактор (`modules/image-to-gaps/editor.js`, `editor.css`)
Предложения и кнопка «Пропуск» над выделением; значок пропуска в тексте — миниатюра картинки (без картинки — слово пунктиром); панель под пропуском: картинка, «Убрать», описание, выбор (заглушки, «Загрузить картинку», ссылка); «Банк картинок» с фильтрами Все/Ответы/Ловушки и «+ Ловушка». Окно «Какое упражнение создать?» сначала спрашивает модуль.
