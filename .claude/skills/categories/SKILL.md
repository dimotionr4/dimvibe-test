# Categories / Sorting (двенадцатый модуль)

Спецификация: `docs/spec/04_MODULES/CATEGORIES_SORTING.md` (CS-01…CS-04, модуль 12 архива), решения D-088…D-092 в `docs/spec/DECISIONS.md`, приёмка CS-AC-01…26 в `docs/spec/07_DELIVERY/ACCEPTANCE_CRITERIA.md`.

Решения владельца 2026-10-25 («подходят все рекомендации»):
1. Раскладывание двумя способами сразу, без переключателя: нажать карточку, потом категорию — или перетащить карточку. Мышью перенос начинается сразу (после сдвига на 6 px), пальцем — после удержания 250 мс; если палец поехал раньше, это прокрутка страницы.
2. Проверки обычные, как в архиве: 3 при 3–5 карточках, 5 при 6+, автор может выбрать 1–5. Верные закрепляются, неверные на промежуточной проверке возвращаются в банк с ✗, правильная категория не раскрывается. На последней проверке всё замирает на местах.
3. «Показывать правильный ответ» — выключатель во вкладке «Поведение», по умолчанию выключен (как в Ordering и Timeline). Если включён, после конца у неверной карточки подпись «Правильно: <категория>».
4. Вид категорий во вкладке «Дизайн»: «Колонками» (по умолчанию; сетка `auto-fit, minmax(150px, 1fr)`, на телефоне 2 в ряд) или «Друг под другом».
5. Лимиты: категорий 2–5, карточек всего 3–20, карточка до 100 символов, название категории до 60. Одна группа категорий на упражнение. Описания у категории нет (только название).
6. Вставка списком — в этапе 1.
7. Картинки и звук (этап 2, сделан 2026-10-25): карточка — текст, картинка или картинка с подписью, у карточки необязательный звук. В редакторе строкой под полем карточки общие значки `MediaUI.imageControl` с `after: MediaUI.picker('audio')` (миниатюра слева, класс `.cs-media`). В плеере картинка сверху карточки, под ней подпись и маленькая кнопка 🔊 (`audioButton`), лупа — общая `addZoom`. Лупа и звук не выбирают и не переносят карточку (нажатия по `button` внутри карточки пропускаются), проверку не тратят. «Дизайн»: «Размер картинок» S / M / L (56 / 90 / 140 px, вписана целиком, не шире карточки) — только если в упражнении есть картинка. Звук для различения карточек не считается: одинаковые — тот же текст и та же картинка.
8. Банк на телефоне — над категориями, не закреплён. Закреплённый банк — отдельным улучшением, если понадобится.

## Что делает ученик
Сверху банк (`.card.cs-bank`) с перемешанными карточками и подсказкой «Нажмите на карточку, потом на категорию — или перетащите карточку». Под ним категории. Нажатие на карточку выбирает её (повторное — снимает выбор, нажатие на другую — меняет выбор); категории, куда можно положить, обведены пунктиром. Нажатие на категорию кладёт выбранную карточку. Разложенную карточку можно выбрать и положить в другую категорию или вернуть в банк (банк тогда пишет «Нажмите сюда, чтобы вернуть карточку»). Перетаскивание: копия карточки едет за указателем, под ней категория обведена сплошной рамкой, у края области упражнения (`#main`) она прокручивается сама. Строка внизу до проверки: «Разложено: N из M»; после промежуточной: «Верно: X из M · Вернулись в банк: K · Проверок осталось: R».

## Проверка и баллы
- Единица общего хода — карточка (ID единицы = ID карточки): `answer` — ID правильной категории, `value` — ID категории, куда её положил ученик ('' — в банке).
- Своя `check()`: пока в банке есть незакреплённые карточки — `{note}`, проверка не тратится. Иначе верные `locked`, неверные `state: 'bad'`; если проверка не последняя (`checksUsed + 1 < maxChecks`), неверным `value = ''` — они возвращаются в банк с ✗ до следующего переноса. `{done}` — когда все закреплены.
- 1 балл за каждую карточку, один раз (закреплённые не пересчитываются). Число проверок не уменьшается от закрепления.
- Перемешивание — при каждом новом прохождении и «Начать заново»; в предпросмотре редактора порядок держится, пока набор ID карточек тот же. Внутри категории карточки стоят в этом же порядке.
- Обратная связь не только цветом: ✓ / ✗ на карточке.

## Редактор
Категория — блок: поле названия, выше / ниже, копия (новые ID категории и карточек, название «… (копия)»), удаление (не меньше 2 категорий; если есть название или карточки — вопрос «Удалить вместе с карточками (N)?»). Под названием карточки: поле, список «в какую категорию» (смена = новый правильный ответ; пустое единственное поле в новой категории занимается), × удалить (не последнюю). Кнопки «+ Карточка» и «Вставить списком» (каждая непустая строка — карточка этой категории; пустые поля категории убираются, повторы в этой категории пропускаются, сверх 20 не добавляется; итог пишется сообщением). Подсветка сразу: одинаковые названия категорий и одинаковые карточки в разных категориях — красным, повтор в одной категории — жёлтым. Новый черновик — 2 категории по 2 пустых поля.

## Публикация (validate)
Ошибки: категорий меньше 2 или больше 5; категория без названия; повтор названия (без учёта регистра и лишних пробелов); категория без карточек; карточек всего меньше 3 или больше 20; одна и та же карточка (текст без учёта регистра и пробелов) в разных категориях. Предупреждение: одинаковые карточки в одной категории. Пустые поля карточек не ошибка — в файл не попадают.

## Файл упражнения
```json
{ "module": "categories", "format": 1, "showAnswers": true, "view": "stacked",
  "categories": [{ "id": "c1", "name": "Fruits" }, { "id": "c2", "name": "Vegetables" }],
  "imageSize": "m",
  "items": [{ "id": "i1", "categoryId": "c1", "text": "apple", "audio": { "media": "media/…/aud.mp3" } },
            { "id": "i2", "categoryId": "c2", "image": { "media": "media/…/img.jpg", "alt": "" } },
            { "id": "i3", "categoryId": "c2", "text": "carrot", "image": { "url": "https://…", "alt": "" } }] }
```
`categories` — в порядке показа; `items` — по категориям, у каждой ID правильной категории. `showAnswers` — только если включено, `view` — только если «stacked»; `text`, `image` (`media` или `url`), `audio` — только если есть; `imageSize` — только если в упражнении есть картинка. Файлы этапа 1 читаются без изменений. При загрузке: повтор ID получает новый, карточка с неизвестной категорией попадает в первую, категорий добавляется до 2, у пустой категории — одно пустое поле.

## Файлы
Версии: `editor.js` ?v=2, `editor.css` ?v=2, `player.js` ?v=2, `player.css` ?v=2 (этап 2), ASSET_V 67. `modules/categories/`: `editor.js` (`CategoriesEditor`: create, demo, render, load, exportData, validate, unitCount, designOptions, behaviorOptions), `editor.css`, `player.js` (`CategoriesPlayer`), `player.css`. Классы с приставкой `cs-`; карточка плеера — блок `div.cs-chip` (не кнопка: внутри кнопки лупы и звука) с классом `.chip` (Comic рисует овальный контур), а с картинкой — `.card` (прямоугольный контур, иначе высокая карточка становится кругом); стили — `:is(.chip, .card).cs-chip`, потому что общие `.chip` и `.card` из `index.html` заданы позже. Категории и банк — `.card`. Перетаскивание своё (на событиях указателя, копия-«призрак» `.cs-ghost` в `body`, цель — `elementFromPoint` → `[data-drop]`); `core/reorder.js` не подходит (он только для вертикального списка). На время переноса пальцем `touchmove` гасится (`passive: false`), иначе браузер отменит перенос прокруткой.

## Не проверено
Настоящий палец на телефоне (удержание и перенос проверены искусственными событиями `pointerType: 'touch'` и мышью), Safari/Firefox, LearnWorlds iframe, настоящая загрузка файлов картинки и звука (нужен вход владельца; показ проверен на файлах демо-примера); этап 2 владельцем — ещё нет. При размере S лупа (32 px) закрывает заметную часть картинки 56 px — так же, как в Ordering.
