# Стиль «Экшен» (третий стиль упражнения, рядом с Classic и Comic)

Решение владельца 2026-11-20: третий стиль делаем по референсу «экран выбора героя в экшен-игре» (тёмный, диагональный, как страница комикса). Название — «Экшен» (не «Футуристический»). Сейчас готов только макет `docs/mockup-action.html`; в код плеера и редактора стиль ещё не подключён.

## Открытые вопросы
- Тема: стиль всегда тёмный (независимо от темы) или есть светлый вариант (светлый фон, чёрные наклейки). В макете показан тёмный.
- Шрифт: в макете Oswald + Roboto Condensed (OFL, есть кириллица, подключены с Google Fonts только для макета). Для проекта файлы шрифтов нужно положить в `fonts/` и внести в `core/design.js`.
- Анимации по буквам — отдельно, позже.

## Приёмы
- **Скос**: `clip-path: polygon(...)`, срез 8–14 px у одного-двух углов.
- **Наклейка**: белая плашка, чёрный жирный текст заглавными, скошенные углы, поворот −1…−2°.
- **Растр**: точечная текстура (`radial-gradient`, 3–4 px, прозрачность 8–12 %) только на крупных тёмных блоках.
- **Жёлтая полоска**: 3–4 px под заголовком, рядом с полем, слева у инструкции.
- **Жёсткая тень**: без размытия, `4px 4px 0 #000`.
- **Один акцент** (жёлтый); красный и зелёный — только результат.

## Палитра
Фон `#0b0b0d`, панель `#16161a`, светлая наклейка `#fff`, текст `#f2f2f2`, приглушённый `#9a9aa3`, акцент `#ffd400`, верно `#2ecc71`, неверно `#ff3b3b`.

## Элементы
- **Поле ввода / пропуск**: тёмная панель, обводка 2 px серая, скос справа сверху и слева снизу, жёлтая полоска 3 px снизу. Фокус: жёлтая обводка и жёсткая тень. Верно: зелёная заливка, чёрный текст, ✓. Неверно: красная заливка, белый текст, ✗ и короткое смещение (0,3 с). Высота не меньше 44 px.
- **Банк слов**: белые наклейки, чёрный текст, лёгкий поворот ±1°; при перетаскивании +4 % и тень сильнее.
- **Выпадающий список**: тёмное меню со скосом, выбранный пункт на жёлтой полосе.
- **Заголовок**: белая наклейка, жирный заглавный шрифт, жёлтая полоска под ней.
- **Инструкция**: тёмная панель с растром, слева жёлтая полоса 4 px, текст светлый, мелкий, межстрочный 1,5.
- **Метки и счётчики**: светлая наклейка «ПРОВЕРКИ 3/5», табло со светлыми цифрами.
- **Кнопки**: главная — жёлтая, чёрный текст, скос, жёсткая тень (при нажатии сдвиг 2 px); второстепенная — тёмная с жёлтой обводкой; неактивная — серая. Высота не меньше 44 px.
- **Анимации**: общий слой `core/motion.css`, 0,2–0,4 с, только transform и opacity, с учётом prefers-reduced-motion.

## Чего не делать
Скруглений больше 2 px, размытых теней, градиентов (кроме растра), второго акцентного цвета, длинного текста заглавными, тонких шрифтов.
