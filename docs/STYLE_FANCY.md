# Стиль «Fancy» (пятый стиль упражнения)

Решение владельца 2026-11-21: по референсу «приложение для обучения» (пастельные цветные карточки, белые круглые значки, тёмная кнопка-таблетка, крупный жирный заголовок). Палитра — от цвета упражнения (из «Дизайна»): карточки = 20 % акцента на белом, фон светло-серый `#f4f5f7`. Верно / неверно: заливка + значок (✓ мятная `#cdeedd`, ✕ розовая `#f8d3dc`). Макет — `docs/mockup-fancy.html`. Файлы: `core/fancy.css`, `design.style = "fancy"`.

## Приёмы
- Карточки: радиус 36 px (варианты 28 px), без рамок и теней, цвет `color-mix(accent 20%, white)`.
- Поля, пропуски, ярлыки, варианты: белые, радиус таблетки / 22 px, без рамок.
- Кнопка «Проверить» и активные переключатели: цвет упражнения, текст `--on-accent`, таблетка (решение 2026-11-21). Второстепенные — белые.
- Выбор: кольцо акцента 2 px. Заголовок: жирный, крупный.
- Высота элементов касания не меньше 44 px; плеер всегда светлый.

## Ловушки
Поднимать `?v=` и `ASSET_V`; селектор `html.style-fancy:root …`; `--line` прозрачный, рамки на нём пропадают; фиксированные радиусы в `modules/*/player.css`.
