# Стиль «Soft» (четвёртый стиль упражнения, рядом с Classic, Comic и Экшен)

Решение владельца 2026-11-20: по референсу neumorphism / soft UI; название «Soft»; вид — классический лавандовый (вариант 1). Макет — `docs/mockup-soft.html`. Статус: макет и правила; в код ещё не подключён.

## Палитра
Фон и элементы `#eef0f8` (одного цвета), светлая тень `#fff`, тёмная тень `#c9cde0`, текст `#3d4059`, приглушённый `#8a8da6`, акцент `#6c6fe0` (потом — из цвета упражнения, первый «Фирменный» остаётся по умолчанию для других стилей), верно `#3dae7c`, неверно `#d9576b`.

## Приёмы
- Выпуклое: `6px 6px 14px тёмная, -6px -6px 14px светлая`; малое — 3 px / 8 px.
- Вдавленное (поля, пропуски, дорожки): те же тени `inset`.
- Радиусы: карточки 24 px, поля 16 px, кнопки и фишки — таблетка (999 px).
- Рамок и линий нет; активное состояние — вдавливание или тонкое кольцо акцента.
- Главная кнопка — заливка акцентом; остальные — выпуклые, текст акцентом; неактивная — без тени, серый текст.
- Верно / неверно: бледная заливка (зелёная / красная) + значок ✓ / ✕, без узоров.
- Высота элементов касания не меньше 44 px.

## Чего не делать
Резких рамок, жёстких теней, градиентов, второго акцента, тонкого серого текста мельче 13 px.

## Ловушки (из опыта Экшена)
Поднимать `?v=` и `ASSET_V`; селектор `html.style-soft:root …`; не использовать `clip-path` с рамками; проверять фиксированные радиусы в `modules/*/player.css`; плеер у ученика всегда светлый.
