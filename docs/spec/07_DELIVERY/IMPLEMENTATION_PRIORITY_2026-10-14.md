# Приоритет разработки: рабочий вертикальный сценарий
**Статус: APPROVED · 2026-10-14**

1. Базовый проект, авторизация одного администратора, модели упражнений/медиа и Module Registry.
2. Каталог модулей, список упражнений, автосохранение и каркас четырёх вкладок Editor.
3. **Fill Blanks** от создания до Player (включая Text Validator, Gap Engine, проверки, подсказки, аудио).
4. Публикация по стабильному exercise ID и работающий iframe; вручную встраиваемый тест в LearnWorlds, затем обновление через DimVibe без замены кода.
5. **Image to Gaps** через те же Editor/Player Core и правила банков ответов; адаптивность мобильного Player.
6. Media Library с повторным использованием файлов, тегами/фильтрами и безопасным удалением; наращивание каталогов/папок/сеток без блокирования вертикального сценария.
7. Storage Analytics в настройках, дополнительная полировка и остальные модули поэтапно.

## Контрольные проверки
- Учебная активность LearnWorlds с работающим iframe (`height=600`, `width=100%` как стартовый вариант) проходит тест: новая опубликованная версия появляется после повторного открытия без замены кода; это **ещё не подтверждено**, проверить до масштабирования.
- Черновик не виден ученику до публикации; текущий Player run не мигрирует посередине прохождения.
- Результаты учеников не сохраняются и не отправляются в LearnWorlds.
- Для MVP минимум 2 полноценных модуля (не имитация кнопок). 20+ типов в каталоге не равны 20+ реализованным модулям.
- UI управления преподавателями и сложная история версий не являются блокерами.
