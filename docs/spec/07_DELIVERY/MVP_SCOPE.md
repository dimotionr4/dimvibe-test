## Не путать

- Сохранение черновика автора **не означает** сохранение ответов ученика после reload.
- Версии публикации **не являются** историей прохождений ученика.
- Image to Gaps **не режим Fill Blanks**, а отдельный модуль с общим Gap Engine.
- Все дополнительные функции из `SOURCE_ARCHIVE.md`, не перечисленные в M01–M29, не становятся MVP автоматически.
