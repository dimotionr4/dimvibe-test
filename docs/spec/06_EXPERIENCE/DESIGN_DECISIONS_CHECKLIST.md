# Дизайн — быстрый чеклист согласований

**Дата:** 2026-10-14. **Статус:** функционально согласовано; визуальная полировка позже.

- [x] Десктопный Editor, мобильный/планшетный/десктопный responsive Player.
- [x] Верхние вкладки Content / Design / Behavior / Publish.
- [x] Постоянные **две иконки** тем Classic / Comic в хедере; текст названия только в tooltip, мгновенное переключение без смены вкладки.
- [x] Централизованная, расширяемая, версионируемая дизайн-система; индивидуальные переопределения не теряются.
- [x] Инструкция + обложка могут независимо показываться или скрываться; отсутствие обеих допустимо.
- [x] Обложка сверху; также картинка слева, справа, снизу; размеры, contain/cover, фокус, углы.
- [x] Popover для компактных настроек обложки; для выбора видов блоков/пропусков — прямые чекбоксы, сегменты, мини-карточки.
- [x] Текстовые блоки: общие и индивидуальные фон, рамка, выравнивание, интервалы; «сброс к общим».
- [x] В Rich Text: цвет текста и подсветка отдельно от жирного/курсива/подчёркивания.
- [x] Пропуски: линия / рамка / плашка / свободная форма; линия — сплошная или прерывистая; Comic рисованный и скошенный.
- [x] В пропуске ответ полужирный `600`, не крупнее основного текста.
- [x] Номер слева сверху; звук справа сверху; подсказка справа снизу; галочка/крестик слева снизу.
- [x] Индикатор результата на ~25–30% крупнее других; маркеры с наложением на контур, Comic наклейки.
- [x] Промежуточные/итоговые состояния различаются; нет устаревших галочек после редактирования ответа.
- [x] Кнопка проверки: три вида, три выравнивания; итоги **внутри упражнения**, не модальное окно.
- [x] Медиа: размер, позиция, подпись, contain/cover, углы; изменение размеров на холсте; аудиоплеер отдельно от встроенного значка.
- [x] Общий макет: три ширины, три плотности и три фона; адаптивность без ручных мобильных настроек.
- [ ] Точные иконки, цвета, шрифты, SVG-компоненты, анимации (будут уточнены при визуальной реализации).
- [ ] Подробная вкладка «Поведение» — следующий этап работы.
