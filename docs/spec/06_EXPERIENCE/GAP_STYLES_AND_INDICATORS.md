# DimVibe — визуальное оформление пропусков (утверждено)

Дата: 2026-10-14. Этот файл уточняет общие требования Design System и Gap Engine.

## Варианты формы (оба режима Classic / Comic)

1. **Линия** — по умолчанию **сплошная**, альтернативно **пунктирная/прерывистая**. Classic — ровная геометрия, Comic — слегка рисованная/неровная геометрия; пунктир остаётся пунктиром при смене темы.
2. **Рамка** — прямоугольная (Classic), слегка скошенная/неровная (Comic).
3. **Плашка / pill** — гладкая скруглённая (Classic), более свободная/рисованная (Comic).
4. **Свободная форма** — в Classic сдержанная версия; в Comic заметно асимметричная наклейка/контур.

При смене темы сохраняются **выбранный тип** пропуска (линия остаётся линией, пунктир остаётся пунктиром) и индивидуальные настройки. Не вращать текст внутри художественных форм.

## Размеры и текст

Ширина: auto / compact / wide, с адаптацией к мобильному Player и ограничениями доступной ширины. Дополнительная опциональная **нумерация**. Все пропуски имеют общее оформление + индивидуальное переопределение и возможность сбросить к общему. Текст **внутри** пропуска — semibold, ориентир CSS `font-weight: 600`, в отличие от обычного окружающего текста `400`; касается набираемого ответа, проверенного и финального состояния, всех четырёх стилей, обеих тем. Размер текста внутри совпадает с основным для сохранения строки.

## Четыре закреплённые позиции на контуре/линии

| Позиция | Индикатор | Условия |
|---|---|---|
| **Слева сверху** | маленький номер | только когда включена нумерация |
| **Справа сверху** | иконка **озвучки** | только если к данному пропуску привязано аудио |
| **Справа снизу** | иконка **подсказки** | только если к данному пропуску привязана подсказка |
| **Слева снизу** | **зелёная галочка** при верном ответе либо **красный крестик** при ошибке | только после проверки, пока статус актуален |

Метки могут слегка «наезжать» на контур поля; номер особенно в Comic слегка перекрывает левый край. **Индикатор результата на ~25–30% крупнее трёх остальных**: примерный ориентир 29–32px против 22–24px. Эти размеры не финальные спецификации графики. Comic использует асимметричные стикеры разной формы и слегка рисованные края, Classic — аккуратные лаконичные элементы. На линии индикаторы привязываются к концам и над/под ними, а не к несуществующей рамке. Четыре элемента образуют единый неразрывный inline-узел с полем, не отрываются при переносе строки. Индикаторы не должны заслонять вводимое значение, перекрывать окружающий текст или вредить touch/click target. Доступное имя и keyboard focus для аудио/подсказки.

## Пять состояний

- `normal` — ожидает ответ;
- `active` — фокус/ввод;
- `correct` — зелёный акцент + зелёная галочка слева снизу;
- `incorrect` — красный акцент + красный крестик слева снизу, можно поправить пока остались проверки;
- `completed/locked` — редактирование закрыто, но **сохраняется верная/неверная индикация**, не перекрашивать каждый завершённый ответ в одинаково серый.

После изменения ответа устаревшая отметка предыдущей проверки сбрасывается до следующей проверки. Переключение темы не изменяет значения ответов, баллы, статусы или настройки попыток. В MVP преподаватель не конфигурирует цвета пяти состояний вручную: это системные токены темы; расширение позже централизованно.

## Компактный выбор в Design

При выборе формы использовать мини-превью карточки с отметкой выбранного. Если выбрана «Линия», дополнительно показать компактный выбор «Сплошная»/«Прерывистая». Не заставлять преподавателя открывать последовательность поповеров для простого выбора. Конкретные иконки и формы будем уточнять на художественном этапе.
