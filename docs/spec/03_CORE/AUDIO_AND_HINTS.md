# DimVibe — Audio Service и подсказки

Согласованный MVP, описание функциональности (не реализованный код).

## Озвучка

Озвучивание поддерживается для инструкции, выделенного слова, фразы, предложения и поддерживаемых текстовых полей. В «Содержании» три взаимоисключающих инструмента клика по тексту: обычный текст, пропуск, озвучка. Пропуск и озвучка **могут быть одновременно привязаны к одному слову**. Привязка использует стабильные ссылки на структурные диапазоны / элементы, а не непрочную HTML-подстроку. В Player иконка динамика появляется только у реально озвученного элемента; запуск независим от проверок.

Источники аудио: загрузка преподавателем, повторное использование из собственной медиатеки, генерация TTS при наличии настроенного провайдера. TTS — **провайдер-независимый адаптер**, решение о конкретном провайдере и стоимости отложено. Генерированный аудиофайл хранится один раз и повторно проигрывается ученику, не генерируется при каждом воспроизведении. Действия: послушать, скачать, заменить, отвязать; отвязка не удаляет физический файл. Если текст меняется, интерфейс может предупредить об устаревшем аудио. Общие медиаобъекты неизменяемы для опубликованных версий; замена создаёт новую версию/объект, защищая старые публикации.

## Подсказки для пропуска

Для каждого пропуска возможна **текстовая, аудио- или визуальная (изображение)** подсказка. В Player при наличии показывается лампочка в нижнем правом углу пропуска. По нажатию подсказка открывается по требованию. **В MVP без штрафа по баллам и без расходования проверки**. Озвучка слова (справа сверху) и аудиоподсказка (в подсказке справа снизу) — независимые сущности. Храним расширяемую схему на будущее, но **настройки платного раскрытия / штрафов / «только после проверки» НЕ входят в утверждённый MVP**.

## Контекстная панель

Для выделенного текста: создать пропуск, озвучить, форматировать. Для существующего пропуска: ответы/редактировать, подсказки, оформление, удалить пропуск (восстановить исходный текст/форматирование). Для аудио: слушать, скачать, заменить, удалить привязку. Никаких больших постоянно открытых форм.
