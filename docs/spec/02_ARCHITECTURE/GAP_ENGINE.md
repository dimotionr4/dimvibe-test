# Shared Gap Engine

**Статус:** APPROVED (D-017, D-018), детали API — OPEN.

## Владеет

- Представлением и безопасным редактированием текста с атомарными пропусками.
- Созданием, изменением, удалением пропуска, стабильным `gapId` при редактировании соседнего текста.
- Порядком пропусков и перечислением пропусков для Editor и Module Player.
- Инвариантом целостности: один ID на один пропуск, без битых ссылок.

## Не владеет

- Правильными ответами, альтернативами, картинками, дистракторами и оцениванием.
- Общим числом проверок, итогами и публикациями.
- Сохранением черновика или learner-state.

## Ограничение

Для обоих модулей максимум **10 пропусков**; лимит и предложение смыслового разделения контролирует Editor. Engine предоставляет количество и операции, но не дробит материал автоматически и не удаляет данные без подтверждения.

## Приёмка

1. Одна и та же реализация добавляет/редактирует/удаляет пропуски в обоих модулях.
2. После изменения текста неизменённые пропуски сохраняют свои ID и привязанные модульные данные.
3. Попытка создать 11-й пропуск блокируется с понятным объяснением, существующие 10 не теряются.
4. Undo/Redo корректно возвращает разметку и модульные привязки через редактор.
5. Gap Engine не импортирует Fill Blanks или Image to Gaps.

**OPEN:** окончательный формат rich text, схема операций и обработка paste/selection после выбора технологического стека.
