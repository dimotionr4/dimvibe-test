# Module 20 — Label the Diagram (LD) — approved specification v30

**Status:** LD-01, LD-02, LD-03, LD-04, each A–F **explicitly approved** on 2026-10-17. Functional design only. No Codex handoff or implementation claims. The requirements below are bounded by those decisions; do not import unapproved extra modes.

## Purpose and scope
- One authored image per exercise, image from Media Library, with visually anchored identifiable objects and teacher-defined correct label texts. Education use cases: language, geography, biology, anatomy, technical drawings.
- Four authored response formats: **Drag Labels**, **Click to Assign**, **Type Labels**, **Numbered Labels**. Drag and Click are alternative controls over the *same* assignment data and may be switched by the learner without losing answers. Numbered is an authored/visual mode and mobile fallback; Type changes response semantics and is not a learner-toggle substitute.
- Three visual presentations: **On-image**, **Callouts**, **Numbered**; mix On-image and Callouts where authored. Mobile auto-fallback to Numbered preserves object IDs, correct answers and score; visual change alone never alters the published rubric.
- Use shared DIMVIBE editor, Design System (Classic/Comic, Compact/Standard), Media Library, Player Core and LearnWorlds iframe. Author Studio desktop-only; Player mobile/tablet/desktop with touch and keyboard.

## Canonical content model
- `exerciseId`, immutable `publicationVersion`, `imageAssetId` with immutable asset snapshot/version, intrinsic image size/aspect and optional alternative-description metadata; `objects[]` and optional `labelBank[]`, presentation/behavior/design settings.
- Each `object`: stable unique `objectId`, `anchor` **normalized to image content** (u,v between 0 and 1), label box ID and layout coordinate in **composition canvas coordinate frame** (may extend beyond image), callout type straight/elbow with adjustable elbow geometry, authored label text, per-object explicit acceptable Type aliases, optional Text/Audio/Focus hints, number/order metadata. Distinguish anchor space from canvas layout space; map both to displayed image with aspect-preserving contain and container offsets.
- Label cards have stable `cardId` and displayed text, optional distractor flag. Duplicate displayed text may have multiple interchangeable physical card instances; scoring accepts a matching displayed answer for any eligible equal-label target, never arbitrarily ties `card_01` to `leaf_01` when visually identical. In `Reusable Labels` one bank item may fill several allowed target positions; Exact Set default; distractor cards are unscored variants.
- Store source image replacement/revision state so replaced media forces revalidation of every anchor/label position and renewed author confirmation before publish. Preserve old published snapshot for ongoing student sessions.
- Store assignment by `objectId` (optionally source `cardId`), typed value by `objectId`, set of locked correct `objectId`s, checks used, max checks and completed result; all transitions idempotent.

## LD-01 concept approved A–F
- A independent diagram labeling module; B Drag/Click/Type/Numbered; C On-image/Callouts/Numbered; D coordinates, callout and aliases; E 1 point per original target, default shared 3/5 Check; F shared tools and responsive iframe.

## LD-02 Author Studio approved A–F
- **Editor:** Select, Anchor, Label, Callout, Zoom/Pan, Undo/Redo, move, duplicate/delete, numeric edit. Independent anchor, label box and line geometry. Moving an endpoint updates line; Straight and Elbow supported. A callout may extend beyond image within valid composition canvas.
- **Auto Arrange:** Around Image, Left/Right Columns, Minimal Overlap; changes label/layout only, NEVER anchors; Undo should restore previous positions; unresolved conflicts visibly reported.
- **Word bank:** Exact Set (default), With Distractors, Reusable Labels. Duplicate display names valid with separate card IDs and equivalent matching. For Type, author explicitly lists synonyms/alternatives; conservative normalization is case and redundant whitespace by default; do not silently ignore spelling or diacritics or invoke paid AI grading.
- **Design:** Classic/Comic, Compact/Standard, rectangular/rounded labels, straight/elbow lines, dot/number/hidden anchors, thickness, label bank side/bottom/auto, accessible success/error styles, image Zoom.
- **Validation:** image available, >=1 object, every object has label and legal anchor/layout geometry, correct answer reference, bank sufficient for target multiplicity unless reusable; allow meaningful distractors; warn for crossings and overlapping elements, block only inaccessible/out-of-bounds/fully occluded interactive label slots, unresolved image replacement, or unsatisfiable assignments. Preserve incomplete drafts. No publish if referenced required media unavailable. Exact normalized identical Type aliases across different objects warrant warning, not automatic blocking.

## LD-03 Student Player approved A–F
- **Drag:** direct pointer/touch drag, drop to unlocked slot, occupied slot replacement returns displaced card to bank; correct-locked item cannot move. For equal text cards, same-answer interchangeable. Reusable bank item remains available. Keyboard-equivalent Click always available.
- **Click:** label→field OR field→label, active choice visibly clear and cancellable via Escape. Switching Drag ↔ Click preserves bank uses and assignments.
- **Type:** independently editable inputs for each unlocked object; normalize only authored settings and compare with canonical answer or explicit aliases; incorrect/pending remains editable. No mandatory AI. Prevent visually exposing expected names in accessible controls before completion.
- **Numbered:** stable object ID with dynamically recalculated visible numbers; compact numbered anchors and off-image answer panel. On mobile, select number opens related answer field. Numbered fallback alters presentation, not grading.
- **Checks:** default **3 Check** for 1–5 original scored objects, **5** if >=6. Check examines answered unlocked objects; one correct object = 1 point, unique by objectId, locked forever. Incorrect remains editable, blanks remain available. Disable Check before any new/changed unlocked answer; duplicate Check event cannot consume twice. All correct ends early; final Check locks result and then reveals missing labels without awarding them. Distractors never score and never impose negative points. No automatic score penalty for Text/Audio/Focus hints; usage can be counted.
- **Responsive:** source-space anchor/calibrated canvas lines remain aligned at every aspect and zoom. Pan and Drag gestures isolated; Click as touch alternative. Small iframe auto moves bank below image; optional numbered fallback preserves answers. Accessible focus, keyboard Enter/Space/Tab/Escape, labelled unnamed targets without revealing answers, error statuses non-color-only, reduced-motion; alternative authored nonvisual descriptions are encouraged but cannot promise semantic equivalent automatically.

## LD-04 edge cases and acceptance approved A–F
- **Geometry:** anchors normalized within image, label boxes within composition layout including outside-image callouts; resizing, zoom, orientation and iframe recompute both coordinate spaces, maintain anchor-to-line integrity. Crossed callout lines trigger warning not categorical block; totally occluded slots, inaccessible label boxes, or out-of-canvas slots block publication; overlapping anchors warn. Auto Arrange never shifts anchors.
- **Equal names:** identical display text cards have distinct IDs but are interchangeable for scoring when semantically the same; reusable label banks allowed only under explicit authored multiplicity policy. Distractor placed in a target slot means slot incorrect, not minus points. Type aliases allow exact authored alternatives after conservative normalization.
- **Session & media:** replacing image preserves old anchors as draft pending per-anchor revalidation; no quiet remapping, revision publish only after review. Published snapshot immutable for active attempts even if exercise republished; failure of required image blocks Check and gives retry/error, not a fabricated grade. Hint audio error does not erase answers. Restart resets assignments, locked IDs, check budget, hints and result.
- **Scoring:** use originally authored scored object count for 3/5; uncovered auto-revealed answers score zero; unlocked edits may be revised until final; once final, immutable. Repeated or concurrent Check requests idempotent; 1 point maximum per object.
- **Accessibility:** keyboard accessible assignment, focus visible, accessible field/number identification that does not leak solution; authored alternatives for nonvisual consumption must be manually verified. Mobile Numbered fallback keeps semantics.
- **Acceptance:** 36 explicit test cases LD-AC-01–36 in `07_DELIVERY/ACCEPTANCE_CRITERIA.md`; test setup/action/expected results required.

## Explicit scope exclusions / boundaries
- No AI image object detection, automatic text label generation, free semantic grading, or multi-page diagram player in v1. No default offline progress recovery across browser closure; in-session resilience only. No Codex action until separately requested.
- Teacher may edit incomplete drafts without satisfying publication validation. The authoring preview cannot silently mutate student answer key. Module-specific display and data structures must not modify other modules' Behavior Core exceptions.
