# Module 19 — Word Search (WS), functional specification v29
**Approval:** WS-01, WS-02, WS-03, WS-04, each decisions A–F explicitly approved by user. Design/specification only; not implemented; no Codex handoff.

## Purpose and modes (WS-01)
Teacher supplies a list of target words/phrases. Student searches for their letter-cell placements. Word List shows targets; Clues displays teacher-written text/image/audio prompts instead of target strings; Hidden List shows theme and target count/remaining count, never unearned answers. Default Word List; difficulty presets Easy (horizontal forward/right and vertical down), Medium default (plus permitted forward diagonals), Hard (all eight grid directions and reverse arrangements). Teacher may override direction/mode settings; prevent presets from silently overriding explicit edits.

## Author Studio: editor & generated grid (WS-02)
Desktop-only editor, within existing Content / Design / Behavior / Publish architecture. Fast rows, spreadsheet paste/bulk add and per-word editor; each target has stable unique ID, original text, grid token sequence, optional hint content and media refs, and on successful generation fixed placement start/direction/ordered cell sequence. Maintain original spelling for labels; grid tokenization applies language-specific NFC, Unicode grapheme segmentation, case handling, allowed punctuation/spacing removal (e.g. `ice cream` -> `ICECREAM`). Do not transliterate or strip meaningful symbols without language policy. Two different originals that collapse to identical grid token sequences are conflicting targets and block publish. Duplicate targets prohibited even with different clues. Grid generation uses language-appropriate curated filler alphabet/graphemes. Current demo A–Z only is not a product limitation.

Grid size Auto or Custom 5×5 through 20×20 (square default). Auto chooses a mobile-usable practicable size subject to placement; custom allows permitted directions and size. Generator must place **every** target in a straight allowed direction within bounds; intersections only where graphemes match. Validate the *entire* final grid: exactly one unambiguous physical location for each target within enabled directional set, considering canonical reversal of the exact same physical cell run as not a second location. Additional accidental target occurrences, overlaps producing identical/ambiguous sequences, or target prefix/substrings requiring distinct but indistinguishable targets must be corrected by re-filling/replacing before accepted generation. No silent omission. Bounded multi-attempt search/failure must return a useful error (resize, direction or word change) rather than hang. A user-visible Regenerate creates a candidate layout; no mutation of published snapshot until Save/Publish.

Clues: required per target when mode Clues; teacher authored text/image/audio, with Media Library references and suitable accessibility alternatives. Hidden shows teacher topic and total/remaining count, no individual hints shown by default. Teacher may enable hint tiers separately in Behavior. Bulk text-paste, table input and safe preview; do not add malformed rows silently. Editing a target text, target set, size, or directions marks layout stale and blocks publish pending successful Regenerate. Changing clues, title or design does not invalidate layout. Versioned publication pins grid cells, locations, media refs, rules and target IDs; running Player never mutates from later author changes. Unfinished drafts can save.

Design: Classic/Comic style independent of Compact/Standard density, Square/Rounded cells, line or highlighted-cells marking, color tokens without color-only status, layout of list beside/below based on width, found count, low-motion animation; large grid zoom and accessible tap targets. Need not introduce novel visual systems.

## Student Player (WS-03)
Responsive mobile/tablet/desktop, LearnWorlds iframe. Three equivalent selectors: continuous touch/mouse/stylus Drag; two endpoint taps Tap–Tap; keyboard arrows move focus, Enter/Space select endpoints, Escape cancels. Pointer drag recognizes single intended straight horizontal/vertical/45-degree diagonal line; does not accidentally scroll page within active gesture; grid outside retains normal scroll. Interruptions leave no half-credit. Convert endpoint/drag to canonical ordered contiguous cell indices within grid, then compare against pinned placements. Full sequence must match exactly (including allowed reversed selection of same physical cell sequence); never award just because letter string spells a target. Nondirectional reversed tracing of already authored run is accepted regardless of how the generator placed it; this is not permission to place words in additional forbidden directions. Partial/overlong/bent paths fail. More than one word may share crossing cells, but separate target IDs are scored independently.

Correct target immediately locks and displays persistent colored line/cells + textual status, 1 point per unique target ID. Incorrect selections clear with neutral feedback, zero points, zero penalties, no 3/5 check cap. Re-selecting found target says already found; never increments. In Clues, mark the corresponding prompt completed; teacher option may hide found-word spelling until final. Hidden never reveals remaining target list. Hint tiers: direction, starting cell, first two cells where length allows; teacher decides availability and global quota, default tiers 1+2. Hints are free of score deductions and recorded as usage. For Hidden, choose a remaining target without naming it; a repeated identical hint at same tier for same target does not burn quota without new information. Timer optional/off by default, begins on explicit Start (not iframe load), uses elapsed wall-time with robust pause/resume semantics and not naive interval tick counting; time expiry freezes new scoring. All found -> auto complete; manual Finish requires confirmation and locks result. End screen distinguishes found vs revealed remaining targets; reveal awards no new points. Result is foundUnique/totalTarget, percentage optional. Restart resets selections, highlights, hints, timing and score but reuses fixed published grid.

## Edge cases, accessibility, consistency (WS-04)
- NFC + grapheme segmentation for Georgian and other scripts; canonical case handling per selected language; avoid splitting combining marks/emoji sequences into broken cells. Multiword phrases concatenate only removable separators as configured; collisions detected.
- Validate all 8 physical straight-line directions per *enabled placement rules*, whole grid ambiguity (including filler-generated occurrences). Reversal of student gesture vs orientation of placed word is accepted, while disallowed placement orientation remains disallowed.
- Reject impossible dimensions, empty targets, invalid script characters, normalized duplicates, missing per-word Clues, stale/ungenerated grids and broken required media. Report which words/placements fail; don't silently drop.
- Out-of-bounds drag, pointer cancel, multi-touch, resize, zoom and iframe layout changes cannot create phantom answers, misplaced highlighting or duplicate credits.
- Timer expiration, simultaneous successful find, double Finish, repeat events: deterministic finalization/idempotent scoring. Scored target found just before authoritative expiry counts; not after.
- Hint availability/quotas and no penalty explicitly preserved; media errors are accessible and don't leak hidden answers.
- Accessibility keyboard full grid operation, focus ring, descriptive found/not-found statuses, image alt and audio transcript where appropriate, reduced motion, not color-only, magnification for dense 20×20.
- Preserve active publication version for all sessions; no external paid service is required.
