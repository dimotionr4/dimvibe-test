# Шаблон спецификации нового модуля

**Статус:** OPEN до утверждения пользователем.  
**Тип модуля:** `<module-id>`.

## 1. Назначение и сценарий преподавателя
*Заполнить по согласованному описанию.*

## 2. Module Editor
Только специфические поля и действия. Общие вкладки/сохранение/публикация — в Editor Core.

## 3. `moduleData`
Схема, версии, валидация, обязательные поля. Не менять общую схему упражнения.

## 4. Module Player
Взаимодействия ученика, состояние ответов, доступность.

## 5. `validate` / `evaluate`
Готовность проверки, элементы `{id, score, maxScore}`, правила оценивания.

## 6. Границы и зависимости
Переиспользуемые общие компоненты, отсутствие изменений других модулей.

## 7. Критерии приёмки
Позитивные, негативные и пограничные сценарии.

## 8. Открытые вопросы
Без домыслов; зарегистрировать в `OPEN_QUESTIONS.md`.
