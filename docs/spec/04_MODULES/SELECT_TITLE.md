# Select Title — модуль 06

**Статус: APPROVED DESIGN / NOT IMPLEMENTED**  
**Дата:** 2026-10-15  
**Этапы:** ST-01, ST-02 A–E, ST-03 A–F, ST-04 A–D.

## Назначение и границы
Ученик читает текст и выбирает наиболее подходящий заголовок. Одно упражнение включает один или несколько текстов; **каждый текст имеет свой независимый набор заголовков** и ровно один правильный заголовок. Выбор и оценка повторно используют Multiple Choice / Single Choice и общий Behavior Core, а не отдельную систему проверки. Полностью правильный выбор = 1 балл за текст. Результаты прохождения не сохраняются.

## Author Studio — Content (ST-02 A–E)
- Каждый текст — компактный раскрывающийся блок: создание, изменение, дублирование, удаление, перестановка посредством возможностей Editor Core; новые копии получают новые стабильные ID текста и вариантов.
- Текст для чтения: полноценный многоабзацный материал; сохранять абзацы, переносы и поддерживаемое Editor Core форматирование.
- Заголовки: у каждого текста независимый список; **четыре пустых варианта по умолчанию**, минимум **два непустых** при публикации; жёсткого верхнего предела нет. Можно добавлять/удалять/редактировать и менять порядок.
- **Ровно один** вариант назначается правильным; правильность привязана к стабильному `titleOptionId`, а не к позиции в списке.
- Необязательное пояснение преподавателя для каждого текста.
- Необязательные изображение и аудио для каждого текста из общих Media Library/аудиосервисов. Позиционирование картинки относительно текста (верх/низ/лево/право), fit, масштабирование и просмотр используют общие медиа-компоненты, без специальных копий.
- Незаполненные данные допустимы в черновике; публикация блокируется до исправления ошибок с ясной локальной подсказкой.

## Student Player и Design (ST-03 A–F)
- Два режима отображения: **по одному тексту** с кнопками «Назад / Далее» (по умолчанию) или **все тексты** вертикальным списком. Навигация и смена режима не удаляют выбор и другие данные.
- Текст отображается полностью, включая абзацы и форматирование: без искусственного усечения и без вложенной прокрутки; обычная прокрутка страницы/Player.
- Под текстом — отдельная инструкция выбрать лучший заголовок и крупные кнопки заголовков, **без обязательных букв A/B/C**. Выбор новой кнопки заменяет предыдущий до закрепления ответа.
- Перемешивание заголовков необязательно и **включено по умолчанию**. Перестановка привязана к стабильным ID, порядок не меняется в рамках одного прохождения. Может быть выключена преподавателем.
- Медиа текста независимы от выбора: просмотр/увеличение изображения и неограниченное воспроизведение аудио не расходуют проверки и не изменяют ответы. На узком экране боковое медиа перестраивается вертикально, без горизонтального переполнения LearnWorlds iframe.
- Проверяется **весь набор обязательных текстов** через Behavior Core, только когда каждый имеет выбранный заголовок; пустые ответы не расходуют попытку. После проверки правильные ответы закрепляются; неправильные можно исправить, пока прохождение не завершилось.
- Пояснение правильного ответа доступно после успешной проверки; при ошибке скрывается до успешной проверки исправления либо завершения упражнения. После завершения правильный заголовок можно показать через общие результаты Player; до этого преждевременно не раскрывать правильный вариант. Сброс скрывает пояснения и сбрасывает ответы согласно общим правилам.

## Валидация и граничные случаи (ST-04 A–D)
- Отсутствие текстов, пустой текст, менее двух вариантов, пустой вариант или отсутствие корректно назначенного правильного заголовка блокируют **публикацию**, но не редактирование черновика.
- **Одинаковые заголовки в рамках одного текста запрещены при публикации** (сравнение без учёта регистра и лишних пробелов); одинаковые заголовки между разными текстами разрешены. Показать предупреждение, не удаляя данные автоматически.
- Удаление правильного варианта очищает назначение и требует исправления; удаление/сортировка других вариантов и других текстов не меняют оставшиеся назначения. Дублирование создаёт новые ID и корректные ссылки на правильный вариант в копии.
- Перемещение текста сохраняет связанные заголовки, форматирование, изображение, аудио и пояснение.
- Недоступное используемое медиа вызывает предупреждение и блокирует публикацию до исправления; **отсутствие необязательного** аудио, изображения или пояснения само по себе не препятствует публикации.
- Режимы «по одному» и «все» используют те же данные и результаты, работают с клавиатурой, мышью и touch внутри узких контейнеров.
