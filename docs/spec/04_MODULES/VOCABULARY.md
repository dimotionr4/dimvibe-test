# Module 21 — Vocabulary (VC-01–VC-04)

**Status:** functional design approved, 2026-10-17. VC-01 F (revised informational-only), VC-01 A–E, VC-02 A–F, VC-03 A–F and VC-04 A–F explicitly approved. Implementation not commissioned. This is **not** a quiz or graded exercise. All scores, Check buttons, 3/5 checks, timers, attempts, completion requirements, learner mastery labels, mandatory study progress and SRS are **forbidden**. No answer submissions, results, or achievement/learning progress persistence for this module. Search terms, current card, filter, reveal and playback may exist transiently while Player is open, and are not learning progress.

## 1. Purpose and boundaries
A teacher-owned multilingual illustrated/audio vocabulary dictionary, displayed within the learner-facing responsive Player and embeddable in LearnWorlds. Free exploration of words and phrases, translations, part of speech, example sentences, optional example translation, IPA/transcription, optional image and word/example audio. No automatic translation, semantic correctness assessment or AI prerequisite. Reuse DIMVIBE Media Library, publication snapshots and design system. Future cross-module Vocabulary Library is **architecturally possible but not implemented**; no shared global lexicon or cross-teacher access in v1.

## 2. Schema and identity
- `VocabularySet`: immutable ID, teacher owner, title, optional description, source/translation language tags and text direction, chosen initial view, author ordering, design/style, published-version reference.
- `WordEntry`: immutable entry ID, source lemma/phrase as authored (may contain spaces, punctuation, Unicode), optional IPA or transcription, optional top-level image/media and word audio, order, one or more meanings.
- `Meaning`: stable ID, required part of speech and nonempty translation; optional explanatory note and meaning-specific image; ordered collection of examples. Independent part-of-speech/translation for polysemous words. Meaning order author-controlled. If same spelling occurs in several entries, warn but allow intentionally distinct context after teacher confirmation; never auto-merge by spelling.
- `Example`: stable ID, sentence text when present, optional translation, optional independent audio. Multiple examples per meaning. At least one example **recommended but not mandatory** to publish.
- Each media reference contains media ID/approved immutable-version or publication-safe snapshot information, attribution/alt text when relevant; attached assets obey ownership, audit and lifecycle policies.
- Word and meaning ID do not change when text, position, media or presentation changes. Reordering does not alter identity. No learner answer keys.

## 3. Author Studio (desktop-only)
Quick Table for rapid edits (word, translation, POS, example), Detailed Editor for nested meanings, alternatives, pronunciation, examples and media. Both edit the same normalized records; row reordering, add/duplicate/delete, reversible author editing, autosaved draft. CSV/TSV/paste: preview decoded Unicode content, header-to-field mapping and target language; errors with row+field identifiers; explicit Add New vs Update Existing; updates use stable IDs or explicit matching confirmed by teacher (never silently merge homographs). Validate full batch before atomic commit: cancel/failure leaves current set unchanged. Allow partial draft regardless of publication readiness.

## 4. Media authoring and playback
Word and example audio independently chosen from Media Library, recorded with microphone on teacher-initiated permission, or optional browser-native TTS if locale/voice actually supported. Uploaded/recorded clip takes precedence over *explicitly enabled* TTS. No invented voice, no silent substitution with wrong-language voice; if unsupported/disabled and no playable clip, hide audio control or explain unavailable. A media asset may be attached per word/meaning, with `contain` default or teacher-selected `cover`, crop preview, alt text and no empty placeholder when absent. Protect in-use media from physical deletion or maintain publication-safe referenced versions. Published links persist through edits or safe substitutions.
Player: independent word/example controls, manual play by default, no simultaneous audio within module, changing entry stops previous playback, play/pause/repeat, speeds 0.75×/1×/1.25× where supported, retries on media error, user-gesture fallback to browser autoplay restrictions. Listen queue may optionally autoplay next *after user initiates*, ends after last record (no infinite loop), does not record completion. Close/unmount stops playback. Other optional media failures do not blank word text.

## 5. Learner Player views
- **Dictionary** default: compact list, search word/translation including all meanings, part-of-speech filter, author/alphabetic sort; open detailed entry without losing temporary list context; clear filter and accessible empty state.
- **Cards**: image when present, word, IPA, all meaning blocks (POS, translation, examples and optional translations), audio controls; Prev/Next follow chosen ordering.
- **Reveal**: word shown before translation/examples; learner may reveal content by accessible control. Reveal state is transient and **not a knowledge rating**. Hidden content should not be unintentionally announced by assistive tech before reveal.
- **Listen**: list/sequence of word audio and optional examples; play/pause/replay/skip, bounded queue. Missing audio entries are skipped or clearly identified, never mistaken for pronounced audio.
All views use same published word data, with no duplication and no score/check/attempt/timer/progress. Search/filter/current view state temporary in open session only. Cards and Listen are not Flashcards practice or graded listening.

## 6. Unicode, localization and search
Preserve original author text verbatim for display. Normalize an *independent comparison/search key* in Unicode NFC with language-aware case behavior, grapheme-safe editing and input, Unicode-aware bidirectional layout including RTL as relevant. Preserve semantically significant diacritics. Do not transliterate by default or remove meaningful punctuation. Multi-word phrases, spaces and hyphens supported. In mixed scripts use safe text direction per content and stable ordering. Search across words and all translations, not only first meaning. Text rendering uses genuine Unicode glyphs; do not bake Georgian text into an image.

## 7. Design and responsive behavior
Shared Classic/Comic + Compact/Standard tokens, theme-aware contrast and focus. Design settings for list/card structure, optional example translation and transcription, photo position top/side, `contain`/`cover`, word order and teacher default view. On desktop show list+details where sufficient width; on mobile single-column list and full-width card. No horizontal scrolling for long words in normal sizes, responsive iframe without assumption of parent-assisted resize; usable internal overflow if parent iframe fixed. Accessible semantic headings, buttons, search labels, alt descriptions, transcript/text for recorded pronunciation when available, visible keyboard focus, reduced-motion support and readable 200% zoom. Do not expose extra original translation when Reveal collapsed.

## 8. Validation, publishing, security
Must have >=1 valid entry. Word, >=1 meaning with translation and POS required for each published entry. Missing example/image/audio/IPA is allowed; example absence is nonblocking warning. Chosen/required referenced media is validated; broken media blocks publish if configured required, otherwise warn and omit or repair appropriately. Duplicate spellings warn and teacher must explicitly confirm intentional duplicates. Draft autosave remains permissible for incomplete or conflicted entries. Publish creates immutable resolved text/media snapshot and stable share URL/iframe; active Player retains loaded version until refreshed, new loads get latest published snapshot. Administrator has platform-wide permissions; Teacher only their own records/assets, with publish/share/iframe of their materials; never browse/change another teacher's materials. Public-by-link follows global DIMVIBE publication policy; do not claim exclusive LearnWorlds access.

## 9. Exception to shared Behavior Core
Vocabulary is **display-only / informational**. No scoring units, no total score, no Check limit, no exercise grading, no wrong/right, no mandatory completion or read-tracking; audio-play counts and Reveal actions are not learning analytics. This module must not accidentally inherit scoring from shared Player Core. Other modules remain unchanged.
