# Media Library — общая библиотека изображений

**Статус: MVP APPROVED (M21), детали хранения OPEN.**

## Обязанности

Загрузка изображения, хранение, повторное использование в нескольких упражнениях, выбор из общей библиотеки, стабильная ссылка/ID. Привязка к пропуску и маркировка ответа/дистрактора — **в Image to Gaps**, не в Media Library. `contain/cover` — настройка отображения, не трансформация исходного файла.

## Критерии приёмки

1. Изображение загружается один раз и выбирается в двух разных упражнениях.
2. Повторное использование не создаёт неявную вторую копию.
3. Редактирование черновика не нарушает изображения опубликованной версии.
4. Отсутствующий/недоступный файл обрабатывается без падения Editor/Player.
5. Пользователь не видит внутренние маркеры правильных ответов в Player.

## OPEN

Форматы, размеры, сжатие, права доступа, удаление, резервное копирование, CORS и безопасная отдача медиа в iframe — решить со стеком и моделью хранения.

## Ссылки на медиа и версии (PROPOSED)

В упражнениях хранить asset IDs, а не бинарные данные или нестабильные временные URL. Старые публикации должны продолжать показывать прежнее изображение даже после замены изображения в черновике. Детали в `../02_ARCHITECTURE/DATA_STORAGE.md`.
