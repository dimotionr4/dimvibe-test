# Module 22 — Mini Dialogues (MD) — approved functional specification

**Status:** complete design; MD-01, MD-02, MD-03, MD-04 decisions **A–F explicitly approved** on 2026-10-22. Documentation-only; no implementation claim, Codex handoff, repository change, cloud work or deployment.

## Product purpose and boundaries
Distinct conversation-first exercise, not ordinary prose Fill Blanks. A single Exercise comprises one or more mini-dialogue blocks, each with **at least two dialogue lines**, an optional scene/title, and 1+ total scored inline gaps. Learner sees authored utterances as ordered speech bubbles with meaningful speaker identity (name/initial/avatar/role), speaker-consistent side/color, and editable gaps directly embedded. Two speakers typically left/right; 3+ speakers distinguish via labels/avatars, never position or color alone. Speaker avatars optional. No branching, live roleplay, learner-recorded voice answers, AI generation, ordering/rearrangement activity, or heterogeneous answer modes in v1.

## Document structure / stable IDs
- ExerciseDocument: id, moduleId `mini-dialogues`, title, instruction, global `answerMode` (`typing`|`word_bank`|`dropdown`), ordered speaker[] and dialogue[], settings, design, immutable publicationVersion reference.
- Speaker: speakerId, displayName, shortLabel/initial, optional avatarMediaId and role description, preferredSide (left/right/auto), design token/color. Speaker identity separate from position and visual theme. No orphan dialogue lines after delete or rename.
- Dialogue: dialogueId, optional title, scene/context, ordered lines[], optional dialogueAudio and its access policy.
- Line: lineId, speakerId, ordered segments[] of typed plain text or GapRef, optional lineAudio and access policy. Store **structured text segments**, not unsafe HTML or index-based string substitutions. Editing surrounding text and moving lines do not change gap ID or answer.
- Gap: gapId, correctAnswer, explicitAcceptedAlternatives[], optional hint, width/display options, optional dropdown options/distractors. No nested/overlapping gaps. Correct answer may be word or short phrase at beginning/middle/end of utterance; surrounding spaces/punctuation survive round-trip.
- Word Bank Card: cardId, visibleText, eligibility/canonical answer representation, whether distractor, stable ordering and one-use default. Identical texts may have distinct card IDs; interchangeable where accepted by target. Correct cards/alternatives must be physically placeable in enough quantity in the bank (or explicitly reusable when configured). Distractors never independently scored.
- Audio: optional line and dialogue references in Media Library, availability policy `always` (default), `after_finish`, or `selected_lines` with per-line setting; dialogue-level policy separate. Audio must be absent from pre-finish UI/accessibility tree/network exposure when gated as appropriate to avoid answer leakage. Policy applies to player controls and source URLs, not only CSS.

## Author Studio — desktop-only
Workflow: exercise settings/global answer mode → define speakers → add/reorder dialogue blocks → add/reorder lines and choose speaker per line → select span in line and Add Gap → configure correct answers, explicit alternatives and local dropdown options or global bank → configure speaker and bubble design → add optional audio → preview modes/device widths → validate/publish. Support inline gap editing, stable IDs after rename/reorder, drag reorder of lines, undo/redo and safe switching of answer mode with explicit warning if existing mode-specific settings would be lost. Draft may be incomplete. Optional speaker avatar, line audio, dialogue audio, context/title. Upload/recorded media via shared library only insofar as existing Media Library supports it; no inferred TTS requirement.

Word Bank offers Auto from authored correct answers and Manual bank, with hand-added distractors even under Auto. One-use cards dim/cross off when placed, remain reorderable/recoverable until correct Check lock; same text repeated through separate card IDs. Bank at top by default; compact/collapsible bank on phone; keyboard/tap-to-assign and drag. Dropdown choices per Gap, correct answer must be present, alternatives/distractors deduplicated after canonical normalization; long menus must not be clipped by bubble/iframe. Typing uses shared Text Answer Validator: Unicode NFC, case-insensitive default, trim/collapse whitespace and existing configured terminal punctuation behavior; do not autocorrect typo or indiscriminately remove internal apostrophes, accents, meaningful punctuation. Explicit alternatives only.

## Student Player and presentation
Display each dialogue block separately, authored line order. Speech bubbles visually attach to speakers with left/right default, optional avatar, name or initial, consistently applied token palette; use readable labels for 3+ participants. Bubbles wrap long text, including inline fields. `Rounded/Soft/Compact` bubble style, Compact/Standard density, speaker label visibility, left/right alignment policy, per-speaker accent neutral, gap Underline/Capsule/Box, bank top/bottom, Card/Simple block separators. Honor shared Classic/Comic and responsive design tokens. Must not visually or semantically expose answers from hidden fields, option metadata, accessibility names, audio or tooltips.

Global answerMode **one per exercise**: (a) Typing input directly in gap, (b) Word Bank assignment by drag or tap/card then gap, (c) Dropdown inside gap with its own option list; no per-dialogue mixed mode in v1. Responses held by gapId. Editable unmatched answers may be replaced/removed; correct locked answers immutable until Restart. Empty answers remain editable. All dialogue blocks share one global Check, not per-dialogue Checks. Student may scroll freely between blocks, no step gating. Audible line and full-dialogue playback optional, one stream at a time, no autoplay, stop prior when new audio starts, user-controlled, with pre/post-finishing access policy.

## Scoring and attempts (shared Behavior Core)
Each original gap is one independently scored unit; one correct gap = 1 point. `originalGapCount` of 1–5 ⇒ **3** global Checks, >=6 ⇒ **5** global Checks (unless shared per-exercise attempts override within approved 1–5 contract). Count does not depend on number of dialogue blocks, lines, bank cards, or distractors. Correct Check locks answer and keeps point; wrong/empty can be revised until limit. No negative score or duplicate points. Prevent repeated rapid Check, mutation without new answer and double-submit; once all correct, finish immediately. Last Check freezes result, reveals remaining correct responses inside corresponding bubbles *without additional credit*. Restart resets answers, locked flags, bank card state, Check counter and score; retains published authoring content. Report total correct/max and used Checks. Standard hints/feedback must not give answers prematurely. Use immutable publication snapshot per active session.

## Audio leakage and accessibility
Teacher can set audio always available (default), only after completion, or selective by line with separate dialogue-wide audio policy. Audio recording can inherently state correct gap answers: highlight warning in Author Studio, but teacher chooses didactic approach. Gated audio should not expose controls, source URLs or accessible transcript before access time; accessible alternatives must follow same release policy. Audio failure does not block text task; retries possible. Screen readers announce speaker identity, line, inline gap index, status and controls. All answers operable keyboard and touch, not only drag. On mobile, keep bubbles readable, move long dropdown to accessible popover/sheet when necessary, scroll focused typing input into view, collapse oversized bank; responsive iframe height/scroll cannot drop selections. Never identify speakers solely by color or side. Avatar optional with appropriate decorative/semantic alt handling.

## Validation / failures
Block publish if zero dialogues, any dialogue <2 lines, unknown/unassigned speaker, empty line content, no scored gaps overall, gap lacks canonical right answer, broken gap refs, invalid Dropdown missing/duplicate options or no accepted correct option, Word Bank cannot supply a full valid assignment including multiplicity, or speaker deletion leaves orphan lines. Warn for extremely long lines, audio that might reveal answers, awkward side/label configuration, duplicate distractors/overlong word bank and presentation clipping; never require avatar/audio/scene title. Save incomplete drafts. Unicode and punctuation preserve correct text. Removal of gap should confirm cascade of answer options/hints, with undo. Optional media failures preserve existing student work. Author edits published content create a new immutable version; in-flight sessions use original version. Scope of Teacher/Admin permissions in documented future architecture may differ from current single-admin local MVP; implement current single-admin configuration without asserting multi-user roles are deployed.
