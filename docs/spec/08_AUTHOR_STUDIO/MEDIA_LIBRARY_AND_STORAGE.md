# Media Library и аналитика хранилища
**Статус: APPROVED · 2026-10-14**

## Media Library — рабочий каталог, без громоздкой аналитики
- Одно общее хранилище изображений и аудио с многократным использованием asset ID в упражнениях.
- Полноэкранная медиатека из Sidebar, компактный picker в Editor; выбор файла не вынуждает выходить из редактора.
- Загрузка одного или множества файлов, drag-and-drop, предпросмотр картинок и прослушивание аудио.
- Сетка и список, число колонок и масштаб миниатюр, пользовательские предпочтения вида.
- Сортировка, поиск по имени/тегам, фильтры: тип (изображение/аудио), формат, **размер файла**, **разрешение в пикселях**, диапазоны размеров, соотношение сторон/ориентация (1:1, 4:3, 16:9, горизонтальное/вертикальное), дата, для аудио — длительность и формат.
- **Теги**: несколько тегов на файл, автодополнение существующих, массовое назначение, фильтрация по нескольким тегам; теги независимы от папок.
- Папки: настраиваемое название, цвет, иконка; перемещение и массовые операции через плавающую панель аналогично «Мои упражнения».
- На карточке/в свойствах файла: формат, исходные W×H, размер в КБ/МБ, теги, при необходимости где используется. Изменение размера превью не меняет исходник.
- Главный экран медиатеки **не содержит диаграмм использования хранилища**. Достаточно количества файлов и компактной ссылки «Хранилище».

## Настройки → Хранилище (Storage Analytics)
- Отдельный подробный экран, а не большой блок внутри медиатеки.
- Общий объём; объём и число изображений и аудиофайлов; распределение по форматам; крупнейшие файлы; возможные точные дубликаты; неиспользуемые медиа и кандидаты на оптимизацию.
- Метрика по пользователям — в будущем для администратора. На первом этапе один администратор.
- Отличать уникальный размер исходных файлов от дополнительных физических оптимизированных вариантов. Не умножать объём одного файла на количество ссылок в упражнениях.
- Показывать свободный лимит и квоты только если есть достоверные данные провайдера; иначе показывать измеренный объём DimVibe без вымышленного остатка.
- Определять объём по сохранённым metadata storage object, без скачивания файлов для каждого открытия экрана.

## Защита публикаций
Не удалять физически медиа, если на них ссылается опубликованная версия, даже когда пользователь удалил/заменил asset в черновике. Замена создаёт новый объект и не меняет старый файл «под ногами» публикации. Очистка требует проверки ссылок и подтверждения.
