# Администрирование — граница MVP
**Статус: APPROVED · 2026-10-14**

- На текущем этапе **один администратор**, полный доступ к Author Studio, Editor, Media Library, публикациям и настройкам.
- Полноценный Admin Center (приглашения учителей, учётки, управление ролями, админ-дашборды, журнал действий и квоты per user) **отложен**: не является условием готовности первого работающего упражнения.
- Сохранить архитектурную совместимость с двумя будущими ролями Administrator и Teacher, серверные проверки прав, владельца ресурса, защищённый доступ к черновикам. Не заставлять реализовывать пользовательский интерфейс управления преподавателями сейчас.
- Не смешивать архитектурную предусмотрительность с текущей функциональностью: приглашение пользователей в MVP не требуется.
- На первом месте: загрузка/создание/редактирование упражнения, два модуля, аудио/медиа, Student Player, публикация и испытание iframe в LearnWorlds.
