# Module Catalog — каталог типов упражнений
**Статус: APPROVED · 2026-10-14**

## Отображение и навигация
- Модули в центральной сетке с **иконкой, названием и кратким описанием**, по аналогии с прототипом.
- Три вида: **карточки**, **список**, **компактные кнопки-иконки** (у компактных пояснения по tooltip).
- Пользователь выбирает вид, поиск, группировку **по категориям / общим списком**, фильтрацию, сортировку (в т.ч. свой порядок), избранное, скрытие/возврат модулей.
- Для сетки: **2–8 элементов в строке** или автоматическое число колонок; изменение числа колонок автоматически масштабирует ширину карточек и иконок. Отдельно регулируются межэлементные интервалы. Слишком узкое окно временно уменьшает число колонок без утраты предпочтения. В режиме списка настройка колонок не применяется.
- Ручная перестановка модулей перетаскиванием, когда выбран собственный порядок. Персональные предпочтения сохраняются (в MVP для одного администратора, в будущем — per user).
- Категории управляемые, не жёстко зашитые; новый модуль объявляет категорию, название, описание, иконку и доступность через **Module Registry**. Недоступные модули не должны выглядеть рабочими.
- Избранное доступно через Sidebar и/или фильтр каталога. Скрыть ≠ удалить/деактивировать: существующие упражнения продолжают работать.

## Масштабирование
Архитектура рассчитана на 20+ модулей и расширение; новый тип подключается декларативно, без переписывания главного экрана. Фактические названия и категории всех исходных модулей необходимо перенести из реестра прототипа (полный список в текущих материалах не подтверждён); не придумывать названия вместо проверки.

## Критерии приёмки
Три вида отображения; ручные 2–8 и auto колонки; сохранение настроек; фильтр/категории/скрытие/избранное; создание черновика рабочего модуля; безопасное отображение ещё не реализованных модулей.
